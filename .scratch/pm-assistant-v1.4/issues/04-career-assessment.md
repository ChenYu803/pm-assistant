# 04: 十题职业认知测试与通过反馈

**What to build:** 用户完成全部工作场景后参加固定十道教育业务新情境四选一职业认知测试，提交后完成本轮测试并看到得分和逐题解析，可以直接重测；不设置及格线，十题全对时额外看到祝贺，所有完成测试的用户都可进入认知文件入口。

**Blocked by:** #03 - 完整工作场景序列与职业认知反馈

**Status:** ready-for-agent

## 产品经理在 Agent 开始前提供

- `assessment.html`：测试开始、答题中、提交、结果、错题解析、重测和全对祝贺的 HTML 原型。
- `assessment-content.md`：十道固定新情境题的业务背景、选项、答案、逐选项反馈和测试流程文案。
- 十道固定教育业务题目，每道四个选项和唯一正确答案；题目不展示工作场景关联。
- 每道题的错题解释、直接重测文案和全对祝贺文案。
- 游客和已登录用户在测试完成后的不同入口状态说明。

## Agent 负责

- 实现固定十题、四个选项、提交、得分和错题展示。
- 实现逐题解析、直接重测和不限次数重测。
- 提交后显示明确完成反馈；十题全对时额外显示祝贺，并分别连接已登录用户的认知文件入口和游客的登录/注册入口。
- 保证测试内容固定，不调用 LLM，不把测试结果写成真实理解水平或职业适配度结论。
- 不设置及格线或分数拦截；用户完成提交后即可继续后续体验。

## Agent 不负责

- 不自行设计十道题或改变已确认的测试认知目标。
- 不实现认知文件正文和文件下载权限；这些属于 #05。
- 不增加分数排名、等级或失败惩罚。

- [ ] 测试固定十题，每题四个选项。
- [ ] 提交后展示得分、错题和逐题解析。
- [ ] 用户可以直接重测，不限次数。
- [ ] 提交后显示完成反馈并进入正确的认知文件入口；十题全对额外显示祝贺。
- [ ] 游客和已登录用户的认证分流符合原型和 spec。
