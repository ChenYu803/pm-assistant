# 05: 十题职业认知测试与通过反馈

**What to build:** 用户完成全部工作场景后参加固定十道四选一职业认知测试，提交后看到得分和错题，可以回溯或直接重测；十题全对后看到祝贺并进入认知文件入口。

**Blocked by:** #04 - 任务地图、回溯与游客中断继续

**Status:** ready-for-agent

## 产品经理在 Agent 开始前提供

- `assessment.html`：测试开始、答题中、提交、结果、错题、回溯、重测和全对祝贺的 HTML 原型。
- 十道固定题目，每道四个选项、正确答案和题目所属工作场景。
- 每道题的错题解释、建议回溯场景、直接重测文案和全对祝贺文案。
- 游客和已登录用户在测试通过后的不同入口状态说明。

## Agent 负责

- 实现固定十题、四个选项、提交、得分和错题展示。
- 实现每道错题到对应工作场景的回溯入口。
- 实现先回溯再重测、直接重测和不限次数重测。
- 十题全对后显示明确祝贺，并分别连接已登录用户的认知文件入口和游客的登录/注册入口。
- 保证测试内容固定，不调用 LLM，不把测试结果写成真实理解水平或职业适配度结论。

## Agent 不负责

- 不自行设计十道题或改变题目与工作场景的映射。
- 不实现认知文件正文和文件下载权限；这些属于 #06。
- 不增加分数排名、等级或失败惩罚。

- [ ] 测试固定十题，每题四个选项。
- [ ] 提交后展示得分、错题和逐题回溯建议。
- [ ] 用户可以回溯后重测，也可以直接重测，不限次数。
- [ ] 十题全对显示祝贺并进入正确的认知文件入口。
- [ ] 游客和已登录用户的认证分流符合原型和 spec。
