# 05: 受保护的 AI 产品经理认知文件交付

**What to build:** 用户通过十题测试后，可以获得一份产品预先编写的 AI 产品经理职业认知文件；文件的内容与版本稳定，查看和下载均受登录保护，游客登录后能返回并继续查看，已登录用户可以下载完整文件。

**Blocked by:** #04 — 十题职业认知测试与通过反馈

**Status:** ready-for-agent

- [ ] 本票同时确定并交付认知文件的结构、具体内容和版本，不把它拆成单独的内容票与实现票。
- [ ] 文件围绕 AI 产品经理定义、工作方式、相邻岗位区别、AI 提效、AI 创造价值、人机协作、可靠性、交付物、Vibe Coding 成长位置和本次体验回顾组织内容。
- [ ] 文件是产品预先编写的固定交付物，不是根据用户答案动态生成的个人总结、成绩单或用户产品成果。
- [ ] 已登录用户通过测试后可以直接查看文件；游客通过测试后必须注册或登录，认证完成后返回并查看文件。
- [ ] 未登录用户不能查看文件正文，也不能下载文件；登录用户可以下载完整、稳定版本的文件。
- [ ] 登录回跳不会丢失用户已经完成的测试结果和认知文件入口上下文。
- [ ] v1.4 不新增个人文件历史库、公开文件预览或游客下载权限。
