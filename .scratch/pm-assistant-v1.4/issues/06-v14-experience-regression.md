# 06: AI 产品经理入职体验全流程回放

**What to build:** 维护者可以使用固定内容回放完整“AI 产品经理入职体验”：用户无论是否登录，从落地页都沿任务简报、工作场景和职业认知测试这一条顺序路径前进，只在精炼学习笔记下载动作处发生认证分流；同时确认 B 路线不回归。

**Blocked by:** #01 - 落地页与入职体验入口分流；#02 - 入职任务简报与第一个工作场景；#03 - 完整工作场景序列与职业认知反馈；#04 - 十题职业认知测试与通过反馈；#05 - 登录后获取精炼学习笔记

**Status:** resolved

## 产品经理在 Agent 开始前提供

* 完整总入口 HTML：从任务简报走到测试结果页下载动作的可点击原型。
* 已确认的所有主要界面 HTML、资源、固定内容和状态说明。
* 一份最终用户流程清单，标明统一入口、错误选择、本次打开期间的场景回看、刷新重置、有错题、测试完成和认证回跳路径。
* open-design 原型中需要重点检查的桌面端、移动端和动画状态。

## Agent 负责

* 新增确定性的浏览器回放入口，使用固定内容，不调用真实 LLM。
* 回放统一主路径：落地页 → 任务简报 → 工作场景 → 十题新情境测试 → 逐题解析/重测 → 测试完成。
* 分别以未登录和已登录状态进入主路径，确认二者在精炼学习笔记下载动作之前没有流程差异。
* 回放未登录下载路径：测试完成 → 点击“获取精炼学习笔记” → 注册/登录 → 浏览器立即下载；回放已登录下载路径：测试完成 → 点击“获取精炼学习笔记” → 浏览器立即下载。
* 验证已体验场景只能在本次打开期间返回重做，刷新或重新打开后记录重置，且浏览器持久存储和服务端都不保存体验进度。
* 回放 B 路线入口，确认现有四环流程的注册/登录和首个 Agent 入口不回归。
* 报告中区分环境、入口路由、场景内容、测试规则、认证边界、文件权限和 B 路线回归。

## Agent 不负责

* 不在回归票中重新设计界面或补写产品内容。
* 不调用真实模型代替固定内容验证。
* 不把原型中的视觉差异误报为产品行为失败；视觉检查应依据已确认的 HTML 状态和可用性标准。
- [ ] 未登录和已登录用户点击“先认识 AI 产品经理”后，都从同一任务简报开始并走相同主路径。
- [ ] 工作场景支持本次打开期间返回重做；刷新或重新打开后记录重置，不恢复中断进度。
- [ ] 未登录用户点击“获取精炼学习笔记”后被要求注册/登录，认证成功后立即下载；已登录用户点击后立即下载。
- [ ] 未登录主路径不产生服务端用户、项目、工作记录或入职进度，浏览器持久存储也不保存体验进度。
- [ ] B 路线入口及既有四环起始行为不回归。
- [ ] 桌面端、移动端和主要原型状态完成可用性检查。
- [ ] 类型检查、lint、构建、脚本语法和 diff 检查通过；不自动切换真实模型。
