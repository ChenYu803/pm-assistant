# 05: 登录后获取精炼学习笔记

**What to build:** 将十题测试结果页上的“获取精炼学习笔记”变成一次受保护的直接下载动作。已登录用户点击后立即下载产品预先编写的固定文件；未登录用户点击后先进入注册/登录页，认证成功后浏览器立即开始下载，不再进入站内文件查看页。

**Blocked by:** #04 - 十题职业认知测试与通过反馈

**Status:** resolved

## 产品经理在 Agent 开始前提供

- 已完成的 `assessment.html` / 测试结果页原型作为入口视觉基准；本票不需要新增 `career-document.html`。
- 固定文件正文、最终文件名、版本和下载格式。当前固定文件为 `.scratch/pm-assistant-v1.4/career-document.md`，下载文件名为 `AI产品经理职业认知-v1.0.md`，格式为 UTF-8 Markdown。
- 入口文案确认：按钮使用“获取精炼学习笔记”；已登录用户点击后直接下载，未登录用户点击后进入注册/登录页，认证成功后立即下载。

## Agent 负责

- 沿用 #04 测试结果页的现有入口，将按钮及旁边说明更新为“获取精炼学习笔记”的下载语义。
- 为固定文件提供受认证保护的下载响应，并使用稳定的文件名、格式和 `Content-Disposition: attachment`，让浏览器直接开始下载。
- 已登录用户点击按钮后立即开始下载，不经过站内查看页，不需要再次点击下载。
- 未登录用户点击按钮后跳转注册/登录页；认证成功后沿回跳目标立即触发下载，不需要用户再次回到测试结果页或再次点击按钮。
- 未认证的直接下载请求不得返回文件内容；认证取消或失败时不发生下载，用户可以回到测试结果页重新发起。
- 下载固定的产品文件，不生成个人总结、成绩单、动态职业报告或用户专属副本；不为下载创建数据库记录。

## Agent 不负责

- 不自行改写固定文件的产品观点、章节结构、版本、文件名或格式。
- 不制作站内文件查看页、公开预览、游客下载、个人文件历史库或用户成绩单。
- 不修改现有四环文件树和项目成果文件协议。

- [ ] 测试结果页展示“获取精炼学习笔记”入口及与下载一致的说明。
- [ ] 已登录用户点击入口后立即下载完整固定文件，不出现站内查看页或第二个下载步骤。
- [ ] 未登录用户点击入口后先进入注册/登录页，在认证完成前不会下载文件。
- [ ] 未登录用户认证成功后浏览器立即开始下载，不需要再次点击入口。
- [ ] 未认证的直接下载请求不会泄露固定文件内容，认证取消或失败时不会产生下载。
- [ ] 下载内容、文件名、格式和版本与产品经理提供的固定文件一致，且不创建数据库记录。

## 相关 spec

见 v1.4 spec 的“精炼学习笔记下载”“下载交付”“认证边界”和“文件责任”。
