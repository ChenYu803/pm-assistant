# 01: 落地页与 A/B 路径分流

**What to build:** 用户打开 PM Assistant 首屏时，可以从“迷失方向了？”进入“先了解 AI 产品经理”或“直接开始做产品”两条清晰路径；A 路线根据登录状态进入强流程第一关或关卡选择页，B 路线继续进入现有四环产品实践。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 首屏清晰呈现“迷失方向了？”及 A/B 两条路径，用户无需先理解项目、工作记录或 Agent 概念。
- [ ] 未登录用户点击 A 后无需注册，直接进入 A 路线第一关；不创建用户、项目、工作记录或服务端关卡进度。
- [ ] 已登录用户点击 A 后直接进入关卡选择页；所有关卡默认开放，并以箭头、高亮或同等明确方式推荐第一关。
- [ ] 用户点击 B 后继续进入现有注册/登录与需求分析 → 原型 → PRD → 任务拆分四环流程，不因 v1.4 入口改版破坏既有行为。
- [ ] 入口在桌面和移动布局下都能清楚区分 A/B，不依赖大段解释性文字才能理解路径差异。
- [ ] 实现使用用户从 open-design 带回的最终 HTML 作为视觉和交互输入；本票不创建 Codex 内部设计原型。
