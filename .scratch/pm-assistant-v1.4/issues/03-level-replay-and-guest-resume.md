# 03: 关卡选择、回溯与游客中断继续

**What to build:** 用户可以像选择游戏关卡一样回看和重复 A 路线内容；游客中断后能在同一设备、同一浏览器继续，登录用户点击 A 后可以直接选择任意关卡；这些体验不建立服务端游客账号或关卡进度。

**Blocked by:** #02 — 单一路径 AI 产品经理职业认知强流程

**Status:** ready-for-agent

- [ ] 游客在 A 路线中离开页面后，再次使用同一设备、同一浏览器打开时可以继续上次体验，不必从第一关重新开始。
- [ ] 游客的中断进度不写入项目数据库，不创建服务端用户、项目、工作记录或关卡完成记录。
- [ ] 跨设备、跨浏览器或清除浏览器数据后的恢复不属于产品承诺，不需要制作迁移或账号绑定流程。
- [ ] 已登录用户从落地页点击 A 后直接进入关卡选择页，所有关卡默认可选，不根据完成状态锁定关卡。
- [ ] 关卡选择页明确推荐第一关，同时允许用户进入任意关卡、回看已体验内容和重复触发场景反馈。
- [ ] 游客完成末尾测试后看到进入关卡选择页的明确按钮或同等引导。
- [ ] 回溯和重复不会改变唯一剧情顺序，也不会产生分支剧情或调用 LLM。
