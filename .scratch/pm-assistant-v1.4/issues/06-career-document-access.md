# 06: 受保护的职业认知文件查看与下载

**What to build:** 用户通过十题测试后获得一份产品预先编写的 AI 产品经理职业认知文件；已登录用户直接查看并下载，游客必须注册/登录后返回查看和下载。

**Blocked by:** #05 - 十题职业认知测试与通过反馈

**Status:** ready-for-agent

## 产品经理在 Agent 开始前提供

- `career-document.html`：文件查看页、游客登录拦截、登录回跳和下载状态的 HTML 原型。
- 认知文件正文、结构、版本和下载格式；内容至少覆盖 AI 产品经理定义、工作方式、相邻岗位区别、AI 提效、AI 创造价值、人机协作、可靠性、交付物、Vibe Coding 成长位置和入职体验回顾。
- 已登录通过用户和游客通过用户的完整状态说明。

## Agent 负责

- 将固定认知文件实现为登录保护的可查看内容。
- 已登录用户通过测试后直接进入文件查看页。
- 游客通过测试后看到注册/登录要求；认证完成后返回原文件入口，不丢失测试通过上下文。
- 未登录用户不能查看正文或下载；已登录用户可以下载完整、稳定版本。
- 保持文件内容固定，不生成个人总结、成绩单或动态职业报告。

## Agent 不负责

- 不自行改写认知文件的产品观点、章节结构或版本内容。
- 不制作公开预览、游客下载、个人文件历史库或用户成绩单。
- 不修改现有四环文件树和项目成果文件协议。

- [ ] 已登录用户通过测试后可以直接查看认知文件。
- [ ] 游客通过测试后必须注册/登录，认证后能返回查看。
- [ ] 未登录用户不能查看正文或下载。
- [ ] 已登录用户可以下载完整固定版本。
- [ ] 登录回跳不丢失用户的测试通过状态和文件入口。
