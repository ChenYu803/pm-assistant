# 07: AI 产品经理入职体验全流程回放

**What to build:** 维护者可以使用固定内容从落地页回放游客和已登录用户的完整“AI 产品经理入职体验”，确认任务简报、工作场景、任务地图、游客继续、职业认知测试、登录回跳和认知文件查看/下载全部满足外部契约，同时确认 B 路线不回归。

**Blocked by:** #01 - 落地页与入职体验入口分流；#02 - 入职任务简报与第一个工作场景；#03 - 完整工作场景序列与职业认知反馈；#04 - 任务地图、回溯与游客中断继续；#05 - 十题职业认知测试与通过反馈；#06 - 受保护的职业认知文件查看与下载

**Status:** ready-for-agent

## 产品经理在 Agent 开始前提供

- 完整总入口 HTML：从任务简报走到职业认知文件入口的可点击原型。
- 已确认的所有主要界面 HTML、资源、固定内容和状态说明。
- 一份最终用户流程清单，标明游客、已登录用户、错误选择、测试失败、测试通过和认证回跳路径。
- open-design 原型中需要重点检查的桌面端、移动端和动画状态。

## Agent 负责

- 新增确定性的浏览器回放入口，使用固定内容，不调用真实 LLM。
- 回放游客路径：落地页 → 任务简报 → 工作场景 → 中断恢复 → 任务地图 → 十题测试 → 错题回溯/重测 → 通过 → 登录 → 文件查看/下载。
- 回放登录路径：落地页 → 任务地图 → 第一关推荐 → 任意场景回溯/重复 → 测试通过 → 文件查看/下载。
- 回放 B 路线入口，确认现有四环流程的注册/登录和首个 Agent 入口不回归。
- 报告中区分环境、入口路由、场景内容、测试规则、认证边界、文件权限和 B 路线回归。

## Agent 不负责

- 不在回归票中重新设计界面或补写产品内容。
- 不调用真实模型代替固定内容验证。
- 不把原型中的视觉差异误报为产品行为失败；视觉检查应依据已确认的 HTML 状态和可用性标准。

- [ ] 游客完整体验通过：任务简报、工作场景、错误反馈、中断恢复、测试、回溯和认证文件。
- [ ] 已登录用户完整体验通过：任务地图、第一关推荐、回溯、测试和文件下载。
- [ ] 游客路径不产生服务端用户、项目、工作记录或入职进度。
- [ ] B 路线入口及既有四环起始行为不回归。
- [ ] 桌面端、移动端和主要原型状态完成可用性检查。
- [ ] 类型检查、lint、构建、脚本语法和 diff 检查通过；不自动切换真实模型。
