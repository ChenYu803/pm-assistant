# 04: 十题职业认知测试与通过反馈

**What to build:** 用户完成 A 路线后，可以参加固定十道四选一职业认知测试；提交后看到得分和错题，能够回溯或直接重测，不限次数，十题全对后获得祝贺并进入认知文件交付入口。

**Blocked by:** #02 — 单一路径 AI 产品经理职业认知强流程；#03 — 关卡选择、回溯与游客中断继续

**Status:** ready-for-agent

- [ ] 测试固定包含十道题，每道题固定有四个选项；题目内容覆盖强流程已经确定的职业认知目标，具体题面和反馈为预编排内容。
- [ ] 用户提交后看到总分、答错题目和每道错题对应的建议回溯关卡。
- [ ] 用户可以选择进入建议关卡学习后再测，也可以不回溯直接重新测试。
- [ ] 测试不限重试次数；每次重测仍需十题全部答对才能通过。
- [ ] 十题全对时显示明确祝贺和 A 路线完成反馈，不把结果描述为对用户真实理解水平的科学测量。
- [ ] 测试通过后为已登录用户提供认知文件查看入口，为游客提供注册/登录后返回认知文件的入口。
- [ ] 测试结果和重试过程不调用 LLM，不因用户选择改变剧情路线或关卡开放规则。
