# 06: v1.4 A/B 全流程回放与发布回归

**What to build:** 维护者可以用固定内容从落地页回放 v1.4 的游客 A、登录 A 和 B 路线，确认职业认知强流程、匿名中断继续、测试、认证文件交付和现有四环入口全部满足外部契约，并得到可定位的最终报告。

**Blocked by:** #01 — 落地页与 A/B 路径分流；#02 — 单一路径 AI 产品经理职业认知强流程；#03 — 关卡选择、回溯与游客中断继续；#04 — 十题职业认知测试与通过反馈；#05 — 受保护的 AI 产品经理认知文件交付

**Status:** ready-for-agent

- [ ] 新增确定性的浏览器回放入口，固定使用预编排内容，不调用真实 LLM。
- [ ] 回放覆盖游客 A：落地页 → 第一关 → 唯一剧情 → 场景选择反馈 → 中断恢复 → 十题测试 → 错题回溯/重测 → 通过。
- [ ] 回放覆盖登录 A：认证用户点击 A → 关卡选择页 → 所有关卡可选 → 第一关推荐 → 回看/重复关卡 → 测试通过 → 直接查看和下载认知文件。
- [ ] 回放覆盖游客认知文件边界：测试通过后不能直接查看或下载，注册/登录后能够返回查看并按权限下载。
- [ ] 回放验证游客路径不新增服务端用户、项目、工作记录或关卡进度数据；已有登录用户和既有工作区数据不被 A 路线污染。
- [ ] 回放覆盖 B 路线入口不回归，既有四环流程的登录、项目/工作记录创建和首个 Agent 入口仍可用。
- [ ] 失败报告能区分环境、路由/认证、内容流程、测试规则、文件权限和既有四环回归，不复制所有子断言噪声。
- [ ] 完成类型检查、lint、构建、脚本语法和 diff 检查；不因 v1.4 验收自动切换真实模型。
