# 04：首页深色视觉与交付物动效

**Status:** resolved
**Risk:** L1，局部前端呈现与输入驱动交互，不修改路由、认证或存储。
**Blocked by:** none

## 用户输入

- 当前 landing page 增加有质感的动效，不使用批量淡入、上移等入场动画。
- 不允许任何白色底面；本票将原暖纸、近白 hover 一并替换为墨黑、暖炭和珊瑚色。
- 用户明确调用 motion-web，复用本产品品牌、内容和两个入口，无新增外部素材。

## 实现方向

- 首屏非对称排版与可切换的成果文件台，鼠标只驱动文件台轻微纵深，触屏与键盘按钮切换同一内容。
- 产品实践区随原生滚动将四份成果接力归档；反向滚动可逆，不拦截滚轮、不拖动整个页面。
- 移动端用自然纵向文档序列，减弱动画与无 JS 均呈现完整静态内容。
- 确定性进度：文件 DOM 暴露阶段和进度 data 属性；验证用真实 pointer、wheel、触屏/键盘事件及计算样式。

## 验收

- [x] 首页全部底面（含 body、外层滚动容器、导航、hover、footer）无白色或近白底。
- [x] 真实鼠标移动会改变文件台姿态，离开后收敛静止；可点击和键盘切换四份成果。
- [x] 真实滚动使交付文件位置与阶段变化，反向滚动可逆，锚点与两个业务入口正常。
- [x] 320/390/768/1440 无横向溢出；减弱动画内容与操作完整。
- [x] tsc、定向 ESLint、生产构建及定向浏览器回归通过；不调用真实模型、不写线上数据。

## 完成与验证边界

移除首页全部滚动淡入与远程 Google Fonts CSS 导入，保留现有中文编辑式字体方向与品牌珊瑚色。首屏使用 CSS 透视和可切换的成果文件扇面；桌面实践段原生 sticky，文件按滚动顺序交接，移动端/矮屏/无 JS/减弱动画呈完整文档列表。渲染层 DOM + CSS；没有引入 GSAP、Three.js 或动效依赖。对应 motion-web 的纵深叠层、滚动驻留与帧率无关指针阻尼，节奏为首屏反馈→安静阅读→实践交接→开始操作。

`verify-landing-motion.mjs` 58/58，通过 320/375/390/414/768/1440 响应式、计算底色、真实鼠标、真实滚轮、四阶段、反向滚动、键盘、独立手机触屏 tap、减弱动画、无 JS 和路由样式隔离；真实滚轮采到 26 个不同文件姿态，反向进度 1.0000→0.6714。TypeScript、定向 ESLint、构建、diff 检查通过，设计检测器无发现。证据：`evidence/landing/`、`landing-verification.log`、`landing-build.log`；只在本机 Chromium 验证，未验收实体中端手机性能或 Safari/Firefox，未推送/部署。
