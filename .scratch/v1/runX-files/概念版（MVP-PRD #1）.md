# 校园二手交易平台（Web）— 概念版

**核心用户**：本校在校大学生——毕业季批量清闲置的毕业生、开学季淘低价教材与生活用品的新生。
**要解决的一件事**：微信群买卖信息混乱、无法结构化检索、无信用评价，导致交易效率低且风险高。
**产品形态**：Web 端（校园二手交易平台），手机号一键登录，图片云存储，消息轮询近实时收发。
**MVP 功能**（3 个）：
1. 商品发布 — 单页一步表单（标题/描述/价格/分类/图片），填完即发。
2. 分类浏览 + 搜索 — 支持按分类筛选与关键词全文检索。
3. 站内私聊 — 买卖双方一对一沟通，记录留存可回查。
**本版本不做什么**：
- 物流配送、担保交易（不涉资金流）、移动 App、高级筛选（价格区间/成色/距离）、消息推送、评价审核与申诉、匿名评价。
**商业模式**：MVP 阶段纯信息撮合，免费开放不收费；后续可考虑置顶推广、交易抽佣或校园广告位作为商业化方向。
**外部依赖声明**：登录走手机号一键登录（学号/手机号注册，实名由学校信息对接或人工核验，不自研实名认证）；图片存储走云存储（如 OSS/COS，不自建存储）；站内消息 MVP 阶段用轮询实现近实时收发，不做 App Push/SMS 推送；不做支付，不依赖支付 SDK，「立即购买」仅表达购买意向，面交时线下支付。
