# 12 — v1.2 综合回放与覆盖报告

**What to build:** 维护者运行一个 replay 综合入口即可验证 v1.2 的安全、冻结、删除、消息恢复、并发、项目隔离、文件协议和 tickets 版本交付，并能从专项结果定位失败类别。

**Blocked by:** #01 — Markdown 安全渲染；#02 — 项目边界与文件参数隔离；#03 — 文件写入协议与 HTML 快照资产；#04 — 项目与工作记录级联删除；#05 — 服务端消息事实源；#06 — 重生成、编辑重发与停止生成恢复；#07 — tab 并发与幂等操作；#08 — 自动命名条件更新；#09 — 显式范围冻结协议；#10 — 消息级文件来源与一致性提示；#11 — 任务拆分 tickets 版本交付

**Status:** claimed

- [ ] 综合入口运行前确认服务端处于 `AI_MODE=replay`，不调用真实模型。
- [ ] 专项覆盖 Markdown 安全、冻结两阶段、级联删除与补偿、消息恢复、tab 并发、自动命名、项目隔离、文件边界、消息级来源和 tickets 版本。
- [ ] 综合入口只汇总专项退出码和类别，不复制专项业务断言。
- [ ] 失败输出包含专项名称和可定位的断言摘要，维护者能据此选择对应 ticket。
- [ ] 回放测试同时检查 UI 外部行为、HTTP/SSE 结果、消息列表、文件列表和数据库关联数据。
