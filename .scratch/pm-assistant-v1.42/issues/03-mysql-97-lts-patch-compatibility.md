# 03：选择并适配适合上线的 MySQL 版本

**What to build:** 根据应用实际 SQL/驱动/迁移行为、目标 Ubuntu 24.04 上可获得的稳定版本、官方支持周期、安全维护和部署验证成本，确定适合本次上线的 MySQL 版本。MySQL 8.0/8.4、9.7 等都只是候选，不预设必须保留当前本机版本或服务器仓库配置。若选择的版本与当前精确版本门禁不一致，按需要调整代码、配置、迁移或备份/恢复工具；以目标服务器实际安装版本完成初始化、生产检查和备份恢复验收后，才记录为上线支持版本。

**Blocked by:** 02 resolved

## 产品经理在 Agent 开始前提供

- 用户于 2026-10-20 明确授权以成功上线为目标调整项目；MySQL 8.0 是举例，不是指定版本。当前目标仍为腾讯云 Ubuntu 24.04 单机部署。
- 目标服务器已安装 Oracle MySQL `9.7.4-1ubuntu24.04`，本机完整验证基线为 9.7.2。结合目标机可用安装包、同一 MySQL 9.7 LTS 系列及避免无必要跨系列迁移，选择 9.7 LTS，运行配置使用 `MYSQL_REQUIRED_VERSION=9.7`。目标机完整专项验收仍待执行，不得把本机 9.7.2 验证冒充 9.7.4 证据。
- 无新增原型或素材。

## 验收标准

- [x] 形成版本选择结论：目标机已安装 9.7.4，同系列本机完整验证基线为 9.7.2；选择 9.7 LTS 系列以复用已验证主/次系列并采用目标机可获取的新补丁版本。
- [x] 代码、环境模板、迁移、部署手册、生产检查、备份和恢复工具统一采用 9.7 LTS 系列边界；其他系列仍拒绝。
