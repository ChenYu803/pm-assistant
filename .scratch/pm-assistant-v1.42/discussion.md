## 2026-10-10 内存优先：Docker 用途与首发建议

用户担心宝塔常驻内存，并询问 Docker 是否必需。当前建议按省资源、少组件优先，保持 Ubuntu 24.04 LTS，首发直接运行 Node.js/Next.js、MySQL 与网站入口，暂不装宝塔或 Docker；这是建议，非已执行部署。宝塔主要提供可视化管理，需要额外资源，但未测版本/插件不能给固定占用或认定 4 GB 无法容纳。4 GB 对外部模型调用、少量面试展示是合理候选，容量仍需生产环境实测，尤其关注数据库缓存和构建峰值。

Docker Engine 是在 Linux 上管理容器的工具，将应用和依赖打包并隔离运行，方便重建/迁移和协调版本；容器共享宿主内核，不是每个容器再装一套完整虚拟机系统。网站和数据库的自身内存仍需付出，Docker 也有额外管理开销，默认容器无资源上限，不会自动给每个站点划定配额；需要显式配置。Docker 不强制搭配宝塔，可在 Ubuntu 后装，云服务器无需 Docker Desktop。未来多应用依赖冲突或部署复现需求明确时再评估容器化，数据库需独立持久化和备份，镜像/配置管理亦有工作成本。

官方依据：[容器概念](https://docs.docker.com/get-started/docker-concepts/the-basics/what-is-a-container)、[Docker 概览](https://docs.docker.com/get-started/docker-overview)、[容器资源限制](https://docs.docker.com/engine/containers/resource_constraints)。本轮仅解释、核对与记录，未装软件、测试容量、部署或调用模型。

## 2026-10-10 镜像追问：宝塔面板与系统镜像的管理差异

用户询问能否改选宝塔 Linux 面板，尚未确认切换；已接受选择仍为广州与 Ubuntu 24.04 LTS。腾讯云提供宝塔应用镜像，含底层 Linux 系统、面板及初始化配置，版本以购买页为准；宝塔是浏览器管理后台，不是独立操作系统，也不是 Linux 桌面。纯系统镜像更常通过 SSH/命令管理；宝塔可可视化管理文件、站点、数据库、证书和资源，但仍可使用 SSH；预装 Docker 镜像侧重容器运行而非网页后台。

## 2026-10-10 当前重点：DeepSeek 调用与 Cloudflare 长响应

用户愿以朋友的美国服务器 + Cloudflare 实测作为访问路线试做依据，当前要求聚焦 DeepSeek 是否为主要问题及解决方法，不反复争论 CDN 路线。重新核对正式代码：`src/lib/ai.ts` 已以 `stream: true` 读取模型；新工作台累计整段回复后才完成消息 API 的 JSON 返回，模型端流式不等于浏览器端流式。故当前明确的适配缺口是端到端及时响应和 Cloudflare 默认 125 秒读取超时，而不是已经发现美国 VPS 无法调用 DeepSeek。

建议优先评估浏览器端流式响应，模型未输出时独立定时发送状态/心跳，配置入口不缓存/不缓冲该响应；收到真实内容及时展示，最终消息和候选仍按完整成功结果提交，覆盖停止/失败/刷新读取。DeepSeek 官方会发 SSE keep-alive，但 SDK 返回内容流不等于这些心跳已转发给浏览器，须独立处理。该方案不必另购云服务或换数据库，有聊天接口/前端协议改动和定向回归成本，实施为 L2，尚未执行。备选为持久生成任务 + 短请求轮询，需任务恢复/失败终态，不能只用不受管理的后台 Promise 冒充可靠任务。

另需在最终实际主机做一次小额、短回答 live 验证，检查 API 地址、Key/余额、模型名称、连接与首个内容耗时；当前未连接 VPS、未调用模型，不能保证美国链路实测。模型计算慢不能由流式或 CDN直接加速，流式改善等待反馈。服务器资源、HTTPS/持久化与登录的部署验收仍保留，但不在本轮展开。官方依据：`https://api-docs.deepseek.com/quick_start/rate_limit/` 与 `https://developers.cloudflare.com/fundamentals/reference/connection-limits/`。

用户对海外 VPS 同机运行 MySQL 感兴趣，要求解释 CDN、美国服务器 + Cloudflare 的合理性，并比较大陆访问便利度；尚未最终选择 VPS 商家、套餐、机房或撤销 Supabase 平台 ADR。新研究见 `docs/research/v142-overseas-mysql-cloudflare-routes.md`。

已核实普通 Cloudflare 的节点取决于网络路由，不能把朋友经过香港理解为免费套餐固定香港线路；China Network 是另购 Enterprise 服务并有 ICP 要求。静态缓存可减少回源，私人数据与生成等动态请求仍由源站处理。Cloudflare 当前官方默认回源读取超时为 125 秒；现有完整生成后 JSON 返回、上游 600 秒等待有超时风险，同机 MySQL 不自动解决该问题。实施时需真正流式/心跳输出及代理缓冲配置或持久任务+轮询；先前 Vercel 300 秒限制不应直接套在常驻 VPS 上，但反向代理与 Cloudflare 限制仍需适配。

用户补充没有朋友的商家、机房、套餐或网站类型信息，不以获取这些信息为前置。朋友路线仅作为方向参考；建议选择短期小额美国 VPS 对照普通代理与 DNS-only 直连，亚洲 VPS 仅按实际大陆运营商线路测量选择，不凭城市保证速度。域名仍可在阿里云注册，DNS 托管可交由 Cloudflare；MySQL 留在服务器内部，不让浏览器或公网直接连接。当前仅解释和研究，不创建资源或执行部署。
