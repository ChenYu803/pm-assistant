# 03：防止交互控件误显文字插入光标

**What to build:** 审查非编辑交互控件中的文字插入光标/误选行为，并统一避免按钮、链接、折叠项和选择项被当作可编辑文字；保留真实输入区域的编辑与复制能力。

**Blocked by:** none

## 产品经理在 Agent 开始前提供

- 用户反馈：不应出现插入光标的文本，在点击时仍会出现；要求检查并修正所有此类位置。
- 解释边界：非编辑控件文字不可误选；正文仍可选择复制；输入框、文本域和 Markdown 编辑器保留编辑光标。

## 验收标准

- [x] 源码无误设为 `contenteditable` 的普通界面文本。
- [x] 仅真实输入框/文本域显示编辑光标颜色。
- [x] 按钮、链接、折叠项、按钮/标签页/菜单项角色和单选/复选选项文字不可误选。
- [x] 普通正文仍可选择复制，文本输入和 Markdown 编辑保持可用。
- [x] Playwright 代表性界面验证控件无文字选区、正文可选择、输入控件可编辑；TypeScript、定向 ESLint 和 `git diff --check` 通过。

**Status:** resolved

**Risk:** L1（全局交互控件文字选择样式，不改变交互逻辑或数据）。
