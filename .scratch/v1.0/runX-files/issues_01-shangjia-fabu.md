# 01 — 卖家发布

**What to build:** 卖家从首页进入发布页，以单页一步表单填写标题、描述、价格、分类并上传图片，点「一键发布」后商品创建成功并返回首页，新商品出现在列表顶部且状态为「在售」。未登录用户触发登录引导后回到发布页继续操作。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 当我在发布页填写标题/描述/价格并选分类、上传图片后点「一键发布」→ 校验通过则商品创建成功 → 返回首页，新商品出现在列表顶部，状态为「在售」。
- [ ] 当必填项为空或价格非法 → 系统在表单内提示「请填写标题/描述/价格」→ 不提交，表单保持原样可修改。
- [ ] 当我未登录点「＋ 发布我的闲置」→ 系统引导登录 → 登录后回到发布页。
- [ ] 当图片上传失败 → 系统提示重新选择图片 → 不阻塞其他字段填写。
- [ ] 当重复点击「一键发布」→ 按钮防重复，只创建一条商品。

**说明:** 商品实体字段与状态机见 prd.md 第 4.2 章；发布页元素与操作见 prd.md 第 3 章「商品发布页」；文案基调见 prd.md 第 6 章。
