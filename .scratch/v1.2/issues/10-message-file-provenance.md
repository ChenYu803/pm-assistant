# 10 — 消息级文件来源与一致性提示

**What to build:** 系统能准确知道某条消息是否写入了某个文件；重生成后若新旧文件可能不同步，用户可以选择更新或保持不变，不会因同名文件误判来源。

**Blocked by:** #03 — 文件写入协议与 HTML 快照资产；#05 — 服务端消息事实源；#06 — 重生成、编辑重发与停止生成恢复

**Status:** resolved — 消息级来源事实、严格来源写入契约、重生成一致性决策与 replay 专项验证已完成（2026-08-24）

- [x] 每次文件写入持久化消息 ID、文件名、操作类型和版本/状态关联。
- [x] 消息 A 未写入、消息 B 写入同名文件时，重生成消息 A 不会被误判为已写入。
- [x] 重生成新回复不再输出旧回复已写入文件时，用户看到“已写入文件与新回复可能不同步”提示。
- [x] 用户选择更新时走既有文件写入确认流程，选择保持不变时不覆盖文件。
- [x] 刷新和历史数据缺少消息级来源时，旧数据可以按文件名兜底且不会影响新消息的精确判定。
