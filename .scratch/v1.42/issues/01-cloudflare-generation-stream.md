# 01: 新工作台生成期间实时显示回复

**What to build:** 为新工作台的发送、编辑重生成和重新生成提供端到端流式回复。浏览器应在 Agent 生成时逐步显示正文；上游暂时没有正文时仍需发送心跳，避免 Cloudflare 普通代理因长时间无响应而超时。最终消息、候选和原型快照仍以服务端成功事务为准，生成中的正文可在刷新后恢复。

**Blocked by:** None

## 产品经理在 Agent 开始前提供

- 用户已在 2026-10-17 明确选择“显示逐步生成”。
- 无新增原型或素材；沿用当前工作台消息区与“生成中”状态。

## 验收标准

- [x] 新工作台发送、编辑后重生成和重新生成时，浏览器按服务端流式事件逐步显示 Agent 正文。
- [x] 模型尚未返回正文时，服务端仍周期性发送心跳；SSE 响应标记为不可缓存并关闭反向代理缓冲。
- [x] 生成中的部分正文可通过既有消息读取接口恢复；最终候选、快照和 completed 状态仍只在完整生成后的现有事务中提交。
- [x] 停止、失败、断线、切换会话和刷新不会把临时回复伪装成已完成内容；成功或终态后界面与数据库事实一致。
- [x] 不请求流式响应的现有 JSON API 调用保持原响应格式与 HTTP 状态。
- [x] 新增固定回放验证覆盖流式事件、心跳、持久化终态及既有 JSON 兼容，不调用真实模型。
