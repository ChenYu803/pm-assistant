# 02：无需服务器即可完成的生产准备

**What to build:** 沿用香港 Ubuntu 24.04、单进程 Next.js + 同机 MySQL 9.7.2、nginx 的路线，补齐生产环境检查、健康检查、异常重启恢复、部署配置与备份/拉取/独立恢复工具。用户于 2026-10-18 选择邀请码注册与账号每日生成上限；不调用真实模型、不连接服务器、不改变本机库、不执行购买或推送。

**Blocked by:** 01 resolved

## 产品经理在 Agent 开始前提供

- 已购域名 ideastage.top；不要求先 DNS 解析。服务器待购，配置由实际主机复核。
- 邀请体验：邀请码注册、每账号每日次数限制；默认上限作为可改环境配置，并如实说明次数不等于金额。
- 备份：服务器每日导出，Windows 开机后拉取，每周及重要更新后手动上传加密文件至百度网盘；无付费存储与自动上传需求。

## 验收标准

- [x] 新增生产配置模板与只读预检，不输出秘密值；显式 AI 模式、生产 HTTPS 域名、专用 DB 账号、维护凭据隔离。
- [x] 邀请校验在服务端实施，注册页按当前配置显示输入；实际 AI 供应商请求统一原子限额，重启后计数保留，回放不计费。
- [x] 单进程生产启动先检查 schema 与配置并收口异常中断消息，成功消息/候选/快照不受影响；健康接口不暴露配置或用户数据。
- [x] 提供 systemd、nginx HTTP/HTTPS 流式配置、部署/更新/回退命令与 Cloudflare 配置步骤；不伪称已在 Linux 执行。
- [x] 提供加密日备份、可校验的 Windows 拉取及独立空库恢复工具，失败不产生成功标志，不自动覆盖现有库，包含代码/配置恢复信息。
- [x] 隔离 MySQL 验证邀请与并发限额、启动恢复和备份恢复；构建/tsc/定向 lint、Shell/PowerShell 检查通过。真实主机与真实模型验收另列清单。
