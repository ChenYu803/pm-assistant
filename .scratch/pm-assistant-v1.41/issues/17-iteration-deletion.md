# 17: 产品迭代删除与来源生命周期

**What to build:** 用户可以删除产品迭代而不误删项目成果。删除会清理该迭代的工作过程，但保留它创建或修改的项目文件、备份、HTML 快照和来源记录；来源显示为已删除迭代占位，任务文件夹进入只读归档。

**Blocked by:** 08: 原型 HTML 快照；12: 文件详情、改名、删除与来源时间线；14: 任务拆分整套提交；16: 阶段会话删除

## 产品经理在 Agent 开始前提供

- 实施模式：复用已落地界面。
- 无新增输入。复用 01 已落地的迭代管理和 16 的危险操作确认，在正式产品中补齐删除范围、进行中阻止、已删除来源占位、只读任务归档和无当前迭代浏览。

**Status:** ready-for-agent

- [ ] 有生成或写入进行中时不能删除迭代；阻止时原对象和候选保持不变。
- [ ] 删除迭代后其阶段会话、消息、候选和工作状态消失，但项目文件、备份、HTML 快照和项目级变更记录仍在。
- [ ] 来源显示为“迭代 NN（已删除）”并保留名称快照，不再跳转到已删除页面。
- [ ] 其任务拆分文件夹保留为只读归档，其他迭代不能接管。
- [ ] 没有当前迭代时可以浏览、预览和下载，但不能加载上下文或改变项目文件。
- [ ] 删除整个项目才清理项目级文件和记录；失败或阻止不会显示成已删除。
- [ ] 删除入口和确认沿用 01、16 的正式交互，已删除占位和归档状态可以直接验收。
