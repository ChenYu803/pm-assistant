# 13: 任务文件夹归属与跨迭代只读

**What to build:** 建立任务拆分文件夹与产品迭代的归属和权限边界。每个产品迭代最多拥有一个任务拆分文件夹；所属迭代可以查看、下载、加载并看到自己的整套任务操作入口，其他迭代只能查看、下载和加载其中的 issue，不能修改、删除、重命名、整套更新或撤回。任务集合的实际提交由 14 号票完成，被删除迭代的任务文件夹保留为只读归档。

**Blocked by:** 03: 阶段会话隔离；05: 项目级文件树与基础操作；06: 手动上下文与 Agent 读取边界

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 13 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖任务文件夹列表、所属迭代可操作态、其他迭代只读态和加载上下文的主流程。
- 所属权、只读原因和归档状态的固定文案或复用文件树视觉。

**Status:** needs-info

缺口：任务文件夹归属、所属/非所属迭代的权限视觉和归档状态尚未有实际可访问原型或复用确认。

- [ ] 同一迭代最多有一个任务拆分文件夹；issue 使用不复用的系统 NN- 序号，用户只能修改序号后的描述。
- [ ] 所属迭代可以查看、下载、加载和修改自己的任务文件夹。
- [ ] 其他迭代可以查看、下载和加载，但所有修改、删除、重命名、整套更新和撤回请求都被拒绝。
- [ ] 被删除迭代的任务文件夹仍可查看和下载，但显示为只读归档，新迭代不能接管。
- [ ] 归属和只读主流程与已提供原型或复用确认一致。
