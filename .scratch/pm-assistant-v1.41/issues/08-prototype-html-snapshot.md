# 08: 原型 HTML 快照

**What to build:** 在原型设计阶段，根据当前会话和按手动上下文规则加载的文件生成可查看、下载和再次打开的 HTML 原型快照。快照属于项目资产，但不进入项目文件树，也不能被普通上下文文件引用；生成失败时用户能明确看到失败并重试。

**Blocked by:** 03: 阶段会话隔离；06: 手动上下文与 Agent 读取边界

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 08 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖 HTML 生成、预览、下载和再次打开快照的主流程。
- 快照列表/详情的复用视觉、失败和重试的固定文案（如有）。

**Status:** needs-info

缺口：HTML 快照的实际可访问原型、复用来源和失败/重试文案尚未交付。

- [ ] 用户可以查看、下载并再次打开同一 HTML 快照。
- [ ] HTML 快照不出现在项目文件树或上下文文件列表中。
- [ ] 生成失败不会显示为成功；已有快照和未确认候选保持不变并可重试。
- [ ] 快照操作不会自动完成阶段或写入结构化 Markdown。
- [ ] 主流程与已提供原型或复用确认一致。
