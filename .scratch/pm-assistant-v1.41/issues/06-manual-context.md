# 06: 手动上下文与 Agent 读取边界

**What to build:** 让上下文文件区域成为 Agent 读取项目文件正文的唯一入口。用户可以从项目文件树把文件加入当前阶段会话，也可以移除；未加入的文件只以轻量目录元数据显示，Agent 不会自动读取整个项目的正文。

**Blocked by:** 03: 阶段会话隔离；05: 项目级文件树与基础操作

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 06 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖文件树加入上下文、上下文区域和移除文件的主流程。
- 空上下文说明、已加载和未加载的区别，以及需要复用的现有文件树视觉。

**Status:** needs-info

缺口：本票所需的实际可访问原型、复用来源和固定文案/特殊行为说明尚未完整交付。

- [ ] 查看预览或目录不会自动加载文件；只有上下文文件区域的加载操作会加入引用。
- [ ] 空上下文时 Agent 能知道项目、迭代、阶段、目标和轻量目录，但请求中没有未加载文件正文。
- [ ] 目录元数据至少能看到路径、树枝、当前修订、最近正文写入迭代和可撤回状态。
- [ ] 每次发送消息按当前引用读取最新正文，并注入同次读取的修订和来源摘要。
- [ ] 文件被覆盖后下一条消息读取新正文；移除文件后下一条消息不再注入正文。
- [ ] 完整时间线、其他会话消息和项目设计史不会自动进入普通对话；未加载文件被问及时 Agent 明确说明没有读过。
- [ ] 没有当前迭代或阶段会话时加载入口不可用且原因清楚；主流程与原型或复用确认一致。
