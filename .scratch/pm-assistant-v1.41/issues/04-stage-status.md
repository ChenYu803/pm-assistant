# 04: 阶段状态

**What to build:** 为产品迭代的四个阶段提供持久的未开始、进行中、已完成状态。用户创建或打开阶段会话后，阶段变为进行中；只有明确完成操作才变为已完成；重新打开已完成阶段会回到进行中。状态不由文件写入或候选数量自动推断。

**Blocked by:** 03: 阶段会话隔离

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 04 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖阶段状态展示、完成本阶段和重新打开的主流程。
- 未开始、进行中、已完成以及生成中不可完成时的固定文案或复用来源。

**Status:** needs-info

缺口：本票所需的实际可访问原型、复用来源和固定文案/特殊行为说明尚未完整交付。

- [ ] 每个阶段只显示未开始、进行中、已完成三种状态，刷新和换设备后状态保持。
- [ ] 创建或打开阶段会话后变为进行中；只有用户明确完成才变为已完成。
- [ ] 没有文件写入或仍有待确认候选时仍可完成阶段。
- [ ] Agent 生成未结束或未停止时不能完成阶段；生成结束或停止后入口恢复。
- [ ] 重新进入已完成阶段会回到进行中；阶段状态不会因其他迭代或文件树变化自动改变。
- [ ] 状态主流程与已提供原型或复用确认一致。
