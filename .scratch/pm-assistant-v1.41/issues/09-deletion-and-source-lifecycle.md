# 09: 阶段会话/产品迭代删除与来源生命周期

**What to build:** 完成阶段会话、产品迭代和项目文件来源的删除语义。删除工作过程不能误删已经确认的项目成果；删除来源对象后，项目级文件、上一版备份和变更记录仍可解释；正在生成或写入时必须先等待或停止，不能留下悬空请求或半完成结果。

**Blocked by:** 02: 四环导航、阶段状态与多会话；06: 原型快照与原型阶段交付；07: 普通文件修订、一次撤回与变更记录；08: 任务拆分整套提交与归属权限

**Status:** needs-info（删除确认、阻止和已删除来源的关键界面原型或复用确认尚未补齐；补齐后改为 `ready-for-agent`）

## 产品经理在 Agent 开始前提供

### 必须确认

- 删除阶段会话和删除产品迭代的确认界面。
- 有生成/写入进行中时的阻止表现，以及用户应看到的下一步提示。
- “未确认候选会被删除”和“项目文件及来源记录会保留”的区分方式。
- 已删除来源、任务只读归档、没有当前迭代时只读浏览的主要呈现方式。
- 如果不需要新的视觉方案，明确写“复用现有确认弹窗和文件详情视觉风格”。

### 不需要提供

- 级联删除 SQL、归档表结构、请求取消实现、来源快照字段或测试脚本。

## Agent 负责

- 删除阶段会话前检查并提示：该会话中的消息、过程状态和未确认候选会丢失；已经确认的项目文件、上一版备份和项目级变更记录不会因会话删除而消失。
- 阶段会话删除后，历史变更记录保留写入时的产品迭代、阶段和会话名称快照；不依赖被删除会话的外键才能显示。
- 删除产品迭代前检查进行中的 Agent 生成和文件写入；存在进行中操作时拒绝删除并提示等待或先停止。
- 删除产品迭代时删除该迭代的阶段会话、消息、未确认候选和工作状态，但不删除它创建或修改过的项目文件、唯一上一版备份、HTML 快照（若仍在项目资产范围内）或项目级变更记录。
- 产品文件/变更记录中原来源迭代显示为“迭代 NN（已删除）”，保留名称快照但不再提供跳转到不存在的迭代页面。
- 删除迭代所属的任务拆分文件夹保留为只读归档；新迭代不能接管、迁移、编辑或继续更新该文件夹。
- 没有当前产品迭代时，项目访问者仍可查看目录、打开正文和下载；不能创建上下文引用，也不能编辑、重命名、撤回或删除。
- 删除整个项目时，才清理该项目的文件、来源记录、快照和其他项目级资产；不得把迭代删除误实现为项目删除。
- 所有删除和阻止操作失败时，原对象、文件、候选和记录状态保持不变。

## Agent 不负责

- 不让删除迭代自动删除项目文件或重写文件正文。
- 不提供删除项目文件后的正文恢复；文件删除的一次性语义由第 07 票保持。
- 不为来源迭代创建虚假的替代链接或自动迁移到新迭代。
- 不替产品经理扩大删除范围、修改确认文案或设计新的归档业务。

## 验收标准

- [ ] 删除含未确认候选的阶段会话时，确认界面明确说明候选会丢失；确认后候选和会话消失，已确认文件及项目级记录仍在。
- [ ] 删除含进行中生成或写入的阶段会话/产品迭代会被阻止；停止或完成后才能重新操作。
- [ ] 删除产品迭代后，该迭代创建或修改的项目文件、上一版备份和变更时间线仍可查看和使用。
- [ ] 来源显示为“迭代 NN（已删除）”并保留名称快照；来源不再跳转到已删除迭代。
- [ ] 被删除迭代的任务拆分文件夹变为只读归档，其他迭代不能接管或修改。
- [ ] 没有当前迭代时只能浏览、预览和下载，不能加载上下文或改变项目文件。
- [ ] 删除整个项目才清理项目级文件和记录；删除迭代不会误触发项目级清理。
- [ ] 删除失败或被阻止时，不出现“已删除”假状态，也不留下半完成结果。
- [ ] 删除确认、阻止、占位和归档主界面与产品经理提供的原型或明确复用方案一致。
