# 10: 工作台视觉整合与 v1.41 确定性回放

**What to build:** 将前 09 张票整合成一个可长期工作的四环实践工作台，并建立唯一的 v1.41 发布验收入口。桌面端和移动端都要让产品迭代、四环导航、阶段会话、对话、项目文件树、上下文文件区域、候选确认、文件详情和来源信息关系清楚；随后从空 MySQL 数据库执行一条 `AI_MODE=replay` 的完整四环回放。

**Blocked by:** 01、02、03、04、05、06、07、08、09 全部完成

**Status:** needs-info（等待前 09 张票的关键原型输入全部确认；本票不要求重新制作一套原型）

## 产品经理在 Agent 开始前提供

### 必须确认

- 确认前 09 张票已经提供的原型和视觉决定可以组合成最终工作台；若某屏需要特殊布局，指出对应票据和复用关系即可。
- 确认哪些页面/区域沿用既有视觉风格，哪些区域按已提供的 v1.41 原型执行。
- 确认最终检查使用的桌面和移动视口；不需要逐像素设计新的状态。

### 不需要提供

- 新的数据库、API、组件、验证脚本或回放代码。
- 一份覆盖所有页面的重复原型；前 09 张票的已确认输入是本票的视觉事实源。

## Agent 负责

- 将前 09 张票的行为和已确认原型接入同一工作台，统一使用“项目”“产品迭代”“阶段会话”“项目文件树”“上下文文件”等新术语；用户界面不再暴露旧的“工作记录”“Tab”“issues/vN”“changelog”“冻结交付”等退役语义。
- 在桌面和移动视口检查并修正：四环导航、阶段状态、会话切换、对话区、文件树、上下文区域、候选确认、详情/时间线和权限提示没有相互遮挡，长名称能够换行或截断而不覆盖控件，加载/失败/生成状态不造成不可操作的布局跳动。
- 从空数据库开始建立一条 `AI_MODE=replay` 浏览器回放，使用真实应用、公开 API 和 MySQL 可观察结果，不调用真实 LLM。
- 回放至少覆盖：注册/登录、创建项目、创建两个产品迭代、编号递增和名称修改、填写目标与暂不填写目标分支、四环跳过与软门禁、阶段状态变化、多阶段会话、候选确认/放弃/失败重试、项目文件共享、手动上下文加载/移除、普通文件覆盖/修订/一次撤回、用户编辑/改名/删除、来源时间线、任务整套新增/更新/删除/撤回、跨迭代任务只读、删除会话、删除产品迭代和已删除来源占位。
- 回放中注入生成中、写入失败、整套任务失败和跨用户/跨项目请求，确认没有半完成状态或权限绕过。
- 替换旧的综合回放和专项断言中与工作记录、固定文件名、自动加载、工作文档入树、逐 issue 确认、`issues/vN`、changelog 和 freeze 绑定冲突的部分；保留与新模型仍相符的 ownership、大小限制、快照隔离、请求幂等和事务完整性检查。
- 只有新的 v1.41 回放以及必要的类型检查、构建、lint 和相关专项检查通过后，才把本票标记为完成。

## Agent 不负责

- 不在本票新增前 09 张票没有确认过的产品行为、核心文案、视觉方向或业务取舍。
- 不把“视觉整合”理解为只改颜色和间距；也不借整合之名重做 v1.4 入职体验。
- 不以旧版回放通过替代新的 v1.41 空库回放，不迁移或兼容旧数据库内容。
- 不负责组织真实用户测试；本版本的主观视觉评审由产品经理执行，真实用户测试可在版本可用后另行进行。

## 验收标准

- [ ] 工作台第一眼能区分产品迭代、四环导航、阶段会话、对话、项目文件树和上下文文件区域。
- [ ] 桌面与移动视口均可完成核心操作：进入阶段、切换会话、加载/移除文件、发送消息、确认候选、查看详情、撤回和处理权限限制；没有关键控件被遮挡或移出可达范围。
- [ ] 新术语和新文件模型在用户界面、下载内容和回放断言中一致；旧工作记录、Tab、changelog、`issues/vN`、逐 issue 确认和 freeze 交付语义不再作为 v1.41 通过条件。
- [ ] 空库 `AI_MODE=replay` 回放覆盖本票列出的产品迭代、四环、上下文、普通文件、撤回、任务整套、删除和来源生命周期路径。
- [ ] 回放能证明空上下文不泄露正文、未确认候选不落盘、覆盖和撤回修订正确、整套任务不会半提交、跨迭代权限有效、删除来源后记录仍在。
- [ ] 生成中、失败、停止和删除阻止等状态刷新后与服务端事实一致。
- [ ] `npx tsc --noEmit`、`npm run lint`、`npm run build` 和新的 v1.41 replay/相关专项检查通过；未调用真实 LLM。
- [ ] 视觉验收以产品经理确认的前 09 张票原型为准；没有未经确认的 Agent 自创产品决策。
