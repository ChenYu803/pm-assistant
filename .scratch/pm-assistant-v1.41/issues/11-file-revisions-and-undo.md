# 11: 普通文件修订、编辑与一次撤回

**What to build:** 用户可以在当前产品迭代中编辑或覆盖普通文件，并获得递增的内容修订号和一次撤回能力。界面只需提供当前正文、当前修订、编辑/覆盖和撤回所需的最小操作反馈；完整来源时间线、改名、删除和本轮写入视图由 12 号票补充。系统只保留紧邻当前正文的一版备份；撤回写成新的 restore 修订并消耗备份，不提供重做。

**Blocked by:** 07: 需求分析候选与首次耐久写入

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 11 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖文件详情、编辑、覆盖、撤回和无备份状态的主流程；改名和删除由 12 号票接入。
- 编辑保存、撤回成功和撤回不可用的固定文案或复用来源。

**Status:** needs-info

缺口：文件编辑、覆盖、撤回和无备份状态的实际可访问原型或复用确认尚未交付。

- [ ] 创建文件得到修订 1；覆盖和用户编辑得到递增修订。
- [ ] 每次正文变化只保留上一版备份；下一次正文变化替换该备份。
- [ ] 撤回把备份写为新的 restore 修订并消耗备份；撤回后不能重做，下一次编辑会重新建立备份。
- [ ] 覆盖不出现额外过期警告；用户确认的最后一次写入直接生效。
- [ ] 写入失败时正文、备份和修订号保持失败前状态。
- [ ] 主流程与已提供原型或复用确认一致。
