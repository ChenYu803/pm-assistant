# 12: 文件详情、改名、删除与来源时间线

**What to build:** 用户打开文件详情时可以理解当前文件状态和它如何产生：当前路径、当前修订、创建来源、最近正文来源、操作者、时间、可撤回目标和轻量变更时间线。用户可以在当前产品迭代中改名或删除文件；产品迭代还提供本轮写入汇总，正文下载和预览仍保持纯 Markdown。

- [ ] 时间线能区分创建、覆盖、用户编辑、撤回、重命名和删除；重命名和删除不伪装成正文修订。
