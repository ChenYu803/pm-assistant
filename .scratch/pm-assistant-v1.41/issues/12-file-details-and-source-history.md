# 12: 文件详情、改名、删除与来源时间线

**What to build:** 用户打开文件详情时可以理解当前文件状态和它如何产生：当前路径、当前修订、创建来源、最近正文来源、操作者、时间、可撤回目标和轻量变更时间线。用户可以在当前产品迭代中改名或删除文件；产品迭代还提供本轮写入汇总，正文下载和预览仍保持纯 Markdown。

**Blocked by:** 11: 普通文件修订、编辑与一次撤回

## 产品经理在 Agent 开始前提供

- 实施模式：正式代码直接实现。
- 无新增输入。在 05、11 的正式文件界面上补齐详情、改名、删除确认、轻量时间线和本轮写入；Agent 负责把来源、操作者、时间、删除后果和撤回目标组织成可读层级。

**Status:** ready-for-agent

- [ ] 文件详情显示当前路径、当前修订、创建来源、最近正文来源、操作者、时间、可撤回目标和轻量时间线。
- [ ] 时间线能区分创建、覆盖、用户编辑、撤回、重命名和删除；重命名和删除不伪装成正文修订。
- [ ] 产品迭代的本轮写入能列出本轮影响的项目文件。
- [ ] 用户直接操作标记为用户操作，不伪造 Agent 会话或消息来源。
- [ ] 来源对象删除后，已有记录仍能显示写入时的编号和名称快照。
- [ ] 用户明确确认删除后，当前正文和上一版备份不可恢复，但轻量删除占位和来源记录仍可查看。
- [ ] 正文预览和下载不包含 changelog 或系统元数据；详情层级可以直接在正式页面验收。
