# 02: 四环导航与工作区入口

**What to build:** 在产品迭代工作区中始终展示需求分析、原型设计、PRD、任务拆分四个一级阶段。用户可以按推荐顺序工作，也可以跳过、返回或直接进入任一阶段；缺少前置成果时得到影响提示但仍可继续。进入空阶段时，用户能看到开始工作的入口而不会被自动创建会话或发送消息。

**Blocked by:** 01: 创建与管理产品迭代

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 02 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖迭代工作区、四环一级导航和进入各阶段的主流程。
- 四环推荐顺序、缺少前置成果时的固定提示，以及需要复用的现有工作区视觉。

**Status:** needs-info

缺口：本票所需的实际可访问原型、复用来源和固定文案/特殊行为说明尚未完整交付。

- [ ] 四个阶段始终作为一级导航可见，当前阶段和推荐顺序清楚。
- [ ] 用户可以跳过、返回或直接进入任一阶段；缺少前置成果只提示可能影响，不形成硬门禁。
- [ ] 空阶段只展示可执行的开始提示，不自动创建会话、加载文件或发送消息。
- [ ] 刷新或重新进入工作区后，当前阶段和导航位置仍与服务端事实一致。
- [ ] 导航和空阶段主流程与已提供原型或复用确认一致。
