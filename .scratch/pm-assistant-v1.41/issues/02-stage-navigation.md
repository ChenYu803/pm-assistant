# 02: 四环导航与工作台骨架

**What to build:** 将产品迭代的独立工作区实现为可持续扩展的完整工作台骨架：四环一级导航、阶段会话列表、真实聊天主区、项目文件树和当前会话上下文。阶段导航始终可见，允许用户按推荐顺序工作或任意跳转；进入缺少前置成果的阶段时给出可继续的软提示，空阶段只在用户显式点击后创建会话。桌面端采用会话、聊天、文件并列布局，文件区可关闭/展开；移动端纵向适配。

**Blocked by:** 01: 创建与管理产品迭代

## 产品经理在 Agent 开始前提供

- 原型包路径：`.scratch/pm-assistant-v1.41/prototypes/02-stage-navigation.html`。
- 工作台是独立页面；由产品迭代管理页进入，显示当前项目、迭代名称和稳定编号，并提供返回迭代管理的入口；不复用项目管理侧栏。
- 四环推荐顺序固定为“需求分析 → 原型设计 → PRD → 任务拆分”；首次进入需求分析，之后恢复本迭代上次停留阶段。
- 缺少前置成果时采用软提示，允许继续进入；空阶段只展示开始工作的入口，不自动创建会话、加载文件或发送消息。
- 工作台主区包含当前阶段会话列表、会话标题/历史、消息输入和聊天操作；项目文件区在桌面并列，可关闭后展开聊天。
- 视觉复用 AI 产品现场暖纸色/墨黑/骨白/珊瑚、字体角色、细线和纸张材质基线。
