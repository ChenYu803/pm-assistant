# 02: 四环导航与工作区入口

**What to build:** 在产品迭代工作区中始终展示需求分析、原型设计、PRD、任务拆分四个一级阶段。用户可以按推荐顺序工作，也可以跳过、返回或直接进入任一阶段；缺少前置成果时得到影响提示但仍可继续。进入空阶段时，用户能看到开始工作的入口而不会被自动创建会话或发送消息。

**Blocked by:** 01: 创建与管理产品迭代

## 产品经理在 Agent 开始前提供

- 原型包路径：`.scratch/pm-assistant-v1.41/prototypes/02-stage-navigation.html`。
- 工作台是独立页面；由 `01-product-iteration-lifecycle.html` 的“进入工作区”跳转，并通过 URL 传递项目、迭代和本轮目标。
- 四环推荐顺序固定为“需求分析 → 原型设计 → PRD → 任务拆分”；首次进入需求分析，之后按当前迭代上次停留阶段恢复。
- 缺少前置成果时采用软提示，允许继续进入；空阶段只展示开始入口，不自动创建会话、加载文件或发送消息。
- 视觉复用 AI 产品现场暖纸色/墨黑/骨白/珊瑚、字体角色、细线和纸张材质基线；工作台不复用项目管理侧栏。
