# 15: 任务拆分整套撤回

**What to build:** 用户可以撤回任务文件夹最近一次成功的整套变更。系统整体恢复更新前集合：移除本轮新增、恢复被删除、还原被更新正文；撤回消耗唯一旧集合快照，不能重做。

**Blocked by:** 14: 任务拆分整套提交

## 产品经理在 Agent 开始前提供

- 实施模式：复用已落地界面。
- 无新增输入。复用 11 的撤回反馈和 14 的整套结果展示，在正式任务文件夹中实现整套撤回、恢复结果、无快照和不可重做状态。

**Status:** ready-for-agent

- [ ] 撤回原子恢复更新前的完整集合，不能得到部分恢复结果。
- [ ] 恢复被删 issue、移除新增 issue、还原被更新正文后，issue 身份和序号仍稳定。
- [ ] 正文恢复产生新的 restore 修订；纯重命名恢复不增加内容修订。
- [ ] 撤回消耗快照，不提供重做入口；没有快照时入口不可用并说明原因。
- [ ] 撤回确认与结果反馈沿用 11、14 的正式实现，只呈现整套恢复特有信息。
