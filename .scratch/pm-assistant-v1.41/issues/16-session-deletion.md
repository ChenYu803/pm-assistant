# 16: 阶段会话删除

**What to build:** 用户可以删除一个阶段会话。删除前明确说明消息、过程状态和未确认候选会丢失；确认后会话消失，但已经确认写入项目文件的结果和项目级变更记录继续存在。

**Blocked by:** 03: 阶段会话隔离；12: 文件详情、改名、删除与来源时间线

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 16 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖删除会话确认、删除中阻止和删除后的空状态。
- 未确认候选会丢失、已写入成果保留的固定文案或复用确认弹窗视觉。

**Status:** needs-info

缺口：本票所需的实际可访问原型、复用来源和固定文案/特殊行为说明尚未完整交付。

- [ ] 删除确认明确区分会丢失的会话内容和会保留的项目文件/记录。
- [ ] 含进行中生成或写入的会话不能删除，用户得到等待或停止的下一步。
- [ ] 确认删除后消息、过程状态、上下文引用和未确认候选消失。
- [ ] 已确认项目文件、上一版备份和来源时间线仍可查看，来源保留写入时快照。
- [ ] 删除主流程与已提供原型或复用确认一致。
