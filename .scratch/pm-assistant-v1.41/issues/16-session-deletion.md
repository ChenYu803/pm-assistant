# 16: 阶段会话删除

**What to build:** 用户可以删除一个阶段会话。删除前明确说明消息、过程状态和未确认候选会丢失；确认后会话消失，但已经确认写入项目文件的结果和项目级变更记录继续存在。

**Blocked by:** 03: 阶段会话隔离；12: 文件详情、改名、删除与来源时间线

## 产品经理在 Agent 开始前提供

- 实施模式：复用已落地界面。
- 无新增输入。复用正式产品已有的危险操作确认样式，在 03 的会话列表中实现删除确认、进行中阻止和删除后的空状态。

## 实现与验证

- 正式会话列表提供删除入口；沿用危险确认的纸色、墨黑与红色动作，默认聚焦取消，失败可原位重试。删除当前会话后选择剩余会话，最后一个删除后可重新开始；删除其他会话不影响当前草稿与上下文。
- MySQL 删除按项目 → 迭代 → 会话顺序使用 `FOR UPDATE NOWAIT`，写入期间立即返回 409；生成中返回等待或停止提示。事务级联清理会话消息、引用与两类候选，阶段完成状态保持原样。
- 项目文件、唯一正文旧版、任务集合旧快照和 HTML 快照保留；永久来源继续显示原名称，并标注来源会话已删除。
