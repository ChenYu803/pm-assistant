# 05: 项目级文件树与基础操作

**What to build:** 为每个项目提供一棵由所有产品迭代共享的文件树。文件树固定包含需求分析、原型、PRD、任务拆分四个树枝；用户可以浏览目录、打开正文和下载文件。没有当前产品迭代时仍可查看项目文件，但不能进行需要迭代归属的操作；文件重命名由 12 号票接入。

**Blocked by:** 01: 创建与管理产品迭代

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 05 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖四个树枝、普通文件、任务文件夹、预览和下载的主流程。
- 没有当前迭代时的只读呈现和不可操作原因；未提供的视觉明确写复用现有文件树。

**Status:** needs-info

缺口：本票所需的实际可访问原型、复用来源和固定文案/特殊行为说明尚未完整交付。

- [ ] 同一项目的不同迭代看到同一棵文件树，文件树不显示为某个迭代私有资产。
- [ ] 文件树始终只有需求分析、原型、PRD、任务拆分四个树枝，不能新增树枝或跨树枝移动文件。
- [ ] 普通文件可以打开预览和下载，下载得到当前纯 Markdown 正文。
- [ ] 没有当前迭代时可以浏览、预览和下载，但不能加载上下文、编辑、重命名、撤回或删除。
- [ ] 跨用户或跨项目访问被拒绝；主流程与已提供原型或复用确认一致。
