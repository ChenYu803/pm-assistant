# 03: 阶段会话隔离

**What to build:** 用户可以在同一阶段创建多个地位相同的阶段会话，切换会话并分别保留消息和过程状态。每个会话都能独立进入工作区并保留自己的上下文引用；会话之间不串用消息、过程状态或上下文文件。

**Blocked by:** 02: 四环导航与工作区入口

## 产品经理在 Agent 开始前提供

- 原型范围参照 `.scratch/pm-assistant-v1.41/v1.41-prototype-inputs.md` 的 03 号条目；实际 open-design 链接或仓库路径待产品经理交付，并需覆盖创建、切换和查看阶段会话的主流程。
- 多会话列表、当前会话和空会话的布局；会话删除确认由 16 号票提供。

**Status:** needs-info

缺口：本票所需的实际可访问原型、复用来源和固定文案/特殊行为说明尚未完整交付。

- [ ] 同一阶段可以创建至少两个会话，任一会话都能进入工作区。
- [ ] 切换会话后消息和过程状态互不串用；刷新后仍恢复正确会话。
- [ ] 每个会话保留自己的上下文文件引用，不会自动继承其他会话的引用。
- [ ] 创建和切换会话不会改变其他阶段状态，也不会自动写入项目文件。
- [ ] 会话主流程与已提供原型或复用确认一致。
