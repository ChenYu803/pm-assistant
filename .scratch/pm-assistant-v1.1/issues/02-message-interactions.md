# 02 — 消息交互批：操作区（复制/删除）+ 流式三件套 + 文件批量确认

**What to build:** 三块消息层交互（实现建议顺序：先操作区，再流式三件套，最后批量确认）：

1. **消息 hover 操作区**：任意消息 hover 出现操作按钮——「复制」（写入剪贴板的是渲染后纯文本，即剥离协议 marker 的文本）；「删除」（用户/AI 消息均可，确认弹窗，不可恢复，删除后从对话历史消失）。
2. **流式三件套**：① 流式期间发送按钮切换为「停止生成」，点击立即中断，已生成内容保留在对话中并标注中断（刷新后可见）；② 智能滚动——仅当滚动位置接近底部时自动跟随新 token，用户向上翻历史不被打断，回到接近底部恢复跟随；③ 流式期间输入框不禁用（可边等边打字），仅发送按钮禁用。
3. **文件批量确认**：Agent 一次输出多个文件时，待确认弹窗改为列表形态（一次展示全部待确认文件），勾选 + 批量写入/丢弃；「拒绝不落盘」语义保留；工作文档静默写入路径不变。

**Blocked by:** 01 — 体验基础批

**Status:** ready-for-agent

- [ ] hover 消息显示复制/删除按钮；复制的文本不含协议 marker
- [ ] 删除单条消息有确认弹窗，确认后消息从历史消失，不可恢复
- [ ] 流式期间点「停止生成」立即中断，已生成内容保留并标注中断，刷新后可见
- [ ] 向上翻历史时新 token 不强制滚动；接近底部时恢复自动跟随
- [ ] 流式期间输入框可打字、发送按钮禁用；生成完成后可立即发送
- [ ] 多文件输出时一次列出全部待确认文件，勾选批量写入/丢弃；拒绝的不落盘
