# 05 — 编辑并重新发送

**What to build:** 用户消息 hover 出现「编辑」按钮。点击后在输入框（或原位）编辑消息内容，确认后该消息之后的所有消息被移除，以编辑后的内容走既有发送流程重新生成。取消编辑不产生任何变更。

**Blocked by:** 04 — 替换式重新输出（复用其「不重复保存用户消息 + 重生成」的服务端模式；操作区 UI 亦在 02 建立）

**Status:** ready-for-agent

- [ ] 仅用户消息出现「编辑」按钮
- [ ] 编辑重发后，该消息之后的所有消息被移除，新回复基于编辑内容生成
- [ ] 取消编辑不产生任何变更
- [ ] 重发后的对话历史无重复用户消息
