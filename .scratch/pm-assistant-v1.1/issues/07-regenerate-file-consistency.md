# 07 — 重生成与文件一致性提示

**What to build:** 替换式重新输出完成后，比较旧回复已写入项目的文件集合与新回复输出的文件集合——当旧回复的文件已写入、而新回复不再输出该文件时，提示用户「已写入文件与新回复可能不同步」，让用户选择「更新文件」（走既有写入流程，需求分析 append / 其他 replace 语义不变）或「保持不变」。防止 vibe coding 链路拿到新旧不一致的文件。

**Blocked by:** 04 — 替换式重新输出（依赖其「旧回复移除、新回复落地」的时机与数据）

**Status:** ready-for-agent

- [ ] 场景触发（旧回复文件已写入且新回复未输出该文件）时出现一致性提示
- [ ] 选择更新时文件按既有语义更新；选择保持时文件不变
- [ ] 无旧文件写入的场景（或新回复仍输出该文件）不出现提示
- [ ] 本票的提示、确认和文件外部行为可在 `AI_MODE=replay` 固定回放下验证，不依赖真实模型或 API
