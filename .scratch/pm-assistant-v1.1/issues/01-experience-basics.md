# 01 — 体验基础批：文件更新修复 + 工作记录命名 + 流水线空状态引导

**What to build:** 三块无依赖的体验基础，一次交付：

1. **文件更新修复**（L2 级，实现建议先做）：正式文件（需求分析.md/原型.md/prd.md）写入后，后续对话中 Agent 再次输出同名文件时重新触发写入判定（确认弹窗），确认后按既有语义更新（需求分析 append / 其他 replace）；拒绝写入不落盘；工作文档静默写入路径不变；页面刷新后重放历史消息不重复弹窗（判定依据：该消息是否已写入，仅历史重放用文件名兜底）。
2. **工作记录命名与创建一步化**：创建面板含可选名称输入框，输入 + 回车即创建（移除「确认创建」中间步骤）；留空创建显示「未命名」。工作记录列表页行内「改名」按钮、工作区顶栏点击名称改名。AI 自动命名仅对「未命名」生效——用户手动命名（创建或改名）后不再覆盖。
3. **流水线空状态引导**：空工作记录（无标签页）渲染四步流水线全景（需求分析 → 原型 → PRD → 任务拆分，每步 icon + 名称 + 职责一句话），仅「需求分析」可点击创建标签页，后三步锁定（「完成前置步骤后开启」）且点击给轻提示。已有标签页后 TabBar「+」仍走完整 Agent 选择（现状不变）。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 已写入的正式文件在后续对话修改时再次出现写入确认，确认后文件更新（需求分析 append 追加、其他 replace 覆盖）
- [ ] 拒绝写入的文件不落盘（语义不变）
- [ ] 页面刷新后历史消息不重复弹写入确认；工作文档静默写入不受影响
- [ ] 创建面板：填名称回车即建、留空创建显示「未命名」；无「确认创建」中间步骤
- [ ] 列表页行内改名生效；工作区顶栏点击改名生效；改名后 AI 自动命名不再覆盖
- [ ] 空工作记录显示四步流水线全景，仅「需求分析」可点，锁定步骤点击有轻提示
- [ ] 已有标签页后新建 tab 仍可自由选择任意 Agent 类型
