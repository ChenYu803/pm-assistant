## 已确认

- 200 元为本轮开发验收与首批试用累计 API 成本预算；基础设施和邮件费用单列，不自动按月重置。
- 注册使用邮箱、密码、邮箱验证码；验证邮箱后完成注册，账号数量不限。
- 邀请码仅绑定赠送积分，首批 100 个；用户通过营销向作者索取，以建立后续用户调研联系。
- 全部 issues 实现后，由用户人工完成一次真实四环及一次小变更迭代，同时验收流程、成果质量、邮箱验证码、邀请码和积分到账；不为这项人工验收计划拆开发 tickets。

- 用户要求至少提供付费继续使用的渠道，重新讨论首发收费；此前纯免费方向不再冻结。渠道及积分定价未定。

## 当前建议，等待用户讨论

- 优先评估官方 Flash 接入；额度按真实业务成本重新估算，不承诺固定 token 数。
- 免费赠送与付费获取并存。首批可考虑人工确认到账后通过后台入账，保留订单、到账核对及积分流水；自动支付接入暂未选定。
- 既有成本乘数与积分售价共同决定加价关系；更换供应商本身不强制改积分单位，但单次消耗和赠送可用量会变。
- 后台建议包括用户概况、首次使用和成果确认、API 用量与故障、邀请及积分记录、付费入账。CPU/内存等系统监测可复用服务器工具，后台仅保留必要状态，不开发复杂实时图表。
- 对应功能实现仍需自带邮箱验证、兑码唯一到账和计分正确性验证；这不等于给用户的最终人工验收另开任务。
