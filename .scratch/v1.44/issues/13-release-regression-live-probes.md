## 验收标准

- [ ] 复核各前置票已 resolved 且验收标准有证据；本票补跨功能回归，不把各票缺失的主要实现或验证统一留到最后。
- [ ] 从浏览器与应用 HTTP/API、隔离 MySQL 验证账号注册/找回、两个邀请码入口及后台授权，覆盖正常、失败、重试与并发结果。
- [ ] 组合验证赠送优先、混合余额、小数精度、完整输入预算、同账号并行、同会话互斥、零余额未访问上游及本地命名无隐藏模型成本。
- [ ] 组合验证对话和润色的可靠结算、停止、故障立即免单、待核对恢复及 24 小时到期，含进程重启、迟到证据、重复结算与冻结总额；核对唯一结果及资金守恒。
- [ ] 验证人工充值/退款的防重、来源与审计、退款与调用竞争、失败恢复，以及普通用户和跨账号访问限制。
- [ ] 只回归本版触及的四环、文件树、上下文授权、写入确认与来源规则；在桌面和窄屏检查个人中心、工作台与最小后台的余额、状态和可访问性。
- [ ] 邮件和供应商边界替身及时间控制只在隔离环境启用，不以私有函数调用次数、表名或复刻公式作为通过依据；测试数据不混入日常账号或生产资金。
- [ ] 替身验证通过后，复用或补充少量实际注册/找回邮件收信与受控官方 API 核验，核实真实模型、可靠用量、价格依据、流式结束和停止能力；分别标注模拟、本机 live 与尚待 14 核验的目标机证据。
- [ ] 完成编译、相关 lint、生产构建和本版相关完整验证与必要相邻回归，记录命令、环境、结果、已知限制和失败处置，不以 replay 通过宣称生产完成。
- [ ] 累计模型调用支出遵守已定 200 元预算；预计超过 10 分钟的 LLM 级验证先说明时长与假设并取得同意，不批量重跑无关历史对话脚本。

## 验证与完成证据

- 优先复用每张功能票已经有效的证据，只有新增组合、修复或未决风险才补测；真实服务只做小规模针对性核验。
- 保留可定位的发布检查结果，所有真实外部能力均记录证据边界，未完成项不能被已通过的模拟结果遮盖。
- 开工前按实际改动判级，按项目纪律选择验证；涉及账号权限、金额存储、并发或共享调用链时执行相应 L2 检查。以用户可观察行为与持久结果为依据，明确区分隔离测试、本机 live 和目标机证据。
