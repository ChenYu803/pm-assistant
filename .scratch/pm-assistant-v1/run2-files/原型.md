# 原型设计：校园二手交易平台

网页版学生闲置交易平台，线下当面交易，平台只做信息撮合与信用沉淀。不做物流配送、担保交易、移动 App。

---

# 页面清单

## 首页 · 商品广场

- **目的**：全站商品的浏览与检索入口，让买家快速找到目标商品。
- **元素**：
  - 分类导航（「教材」「数码」「生活用品」「其他」）：按分类筛选商品；横向标签式。
  - 搜索框（占位文案「搜索商品名称」）：按标题模糊匹配关键词。
  - 筛选区（价格区间 + 排序「最新 / 价格」）：进一步缩小范围。
  - 商品卡片（显示标题、缩略图、价格、新旧程度、交易校区）：单个商品的概览入口。
  - 发布入口（按钮「发布」）：进入发布商品页。
  - 空态提示（「没有找到相关商品，换个关键词试试」）：搜索无结果时展示。
- **操作**：
  - 点分类标签：切换到对应分类商品列表。
  - 输入关键词搜索：回车提交，展示匹配结果。
  - 设置价格区间 / 选择排序：实时刷新列表。
  - 点商品卡片：进入商品详情页。
  - 点「发布」按钮：进入发布商品页。
- **入口·出口**：从任意页面顶部导航进入；出口到商品详情页、发布商品页。
- **依赖**：商品列表数据（含分类、价格、新旧、校区字段）；搜索按标题匹配。

## 商品详情页

- **目的**：展示单件商品完整信息，并引导买家与卖家建立联系。
- **元素**：
  - 商品大图、标题、价格、新旧程度、交易校区、详细描述。
  - 卖家信息区（昵称、信用分、查看其评价入口）。
  - 私聊按钮（「私聊卖家」）：发起站内会话，自动带入商品名作开场白。
  - 收藏按钮（「收藏」，可选）。
  - 下架提示（「该商品已下架」）：商品不可再交易时展示，并隐藏私聊按钮。
- **操作**：
  - 点「私聊卖家」：创建/进入与该卖家的会话，自动发送「你好，请问 [商品名] 还在吗？」。
  - 点卖家评价入口：跳转卖家主页查看历史评价。
  - 点「收藏」：将该商品加入收藏（不强制）。
- **入口·出口**：从首页/搜索结果点商品卡片进入；出口到站内私聊、卖家主页、回首页。
- **依赖**：该商品数据；卖家信用数据；会话创建功能。

## 发布商品页

- **目的**：让卖家以单页表单快速发布一件闲置商品。
- **元素**：
  - 单页表单（同页一步填完）：标题、描述、图片上传（≤9 张）、价格、新旧程度（「九成新 / 八成新 / 其他」）、交易校区。
  - 提交按钮（「发布」）：校验通过即发布。
  - 校验提示（标红内联文案）：标题必填、价格需≥0、图片≤9 张。
- **操作**：
  - 上传图片：选择并预览，最多 9 张。
  - 填写各字段后点「发布」：通过校验则提示发布成功并跳转「我的」列表；失败则标红提示不提交。
- **入口·出口**：从首页「发布」按钮、我的页「发布」入口进入；出口到「我的」列表、首页。
- **依赖**：图片上传能力；发布后写入商品列表并可被搜索。

## 我的页面

- **目的**：个人中心，管理自己发布的商品、买到的商品与信用评价。
- **元素**：
  - 「我发布的」列表（含「编辑」「下架」操作）：管理自己卖出的闲置商品。
  - 「我买到的」列表（含「完成交易」操作）：查看已购买商品并发起完结。
  - 「我的评价」区（历史评价 + 平均分）：展示被评与已评记录。
  - 私聊入口（「我的私聊」）：进入会话列表。
  - 补评提示：有未完成的评价时引导补评。
- **操作**：
  - 点「编辑」：进入发布页预填该商品信息进行修改。
  - 点「下架」：商品从广场与搜索结果中移除。
  - 点「完成交易」：触发互评流程（见评价页）。
  - 点「我的私聊」：进入会话列表。
- **入口·出口**：从顶部导航「我的」进入；出口到发布页（编辑）、评价页、站内私聊。
- **依赖**：用户发布的商品数据、买入记录、评价数据。

## 站内私聊

- **目的**：买卖双方在不加微信好友的前提下协商细节与约定见面。
- **元素**：
  - 会话列表（按最近消息排序，显示对方昵称与最后一条消息）；列表式。
  - 聊天窗口（文本输入框 + 图片发送）；支持多条消息记录回查。
  - 自动开场白（「你好，请问 [商品名] 还在吗？」）：首次会话自动带入。
- **操作**：
  - 输入文本发送：消息即时出现在会话流。
  - 发送图片：选择本地图片发出。
  - 点会话：打开聊天窗口查看历史。
  - 与同一卖家重复发起：去重合为同一会话，不新建。
- **入口·出口**：从商品详情页「私聊卖家」、我的页「我的私聊」进入；出口到商品详情页、我的页。
- **依赖**：会话创建与去重；消息（文本/图片）存储。

## 评价页

- **目的**：交易完成后双方互评，沉淀信用供后续买家参考。
- **元素**：
  - 触发入口：由任意一方在「我买到的」点「完成交易」后弹出。
  - 维度一「信用态度（按时赴约）」：五颗星打分。
  - 维度二「商品/描述相符度」：五颗星打分。
  - 简短文字评价（选填）：自定义评价内容。
  - 提交按钮（「提交评价」）：提交后落库并展示在对方主页。
- **操作**：
  - 打分 + 留言后点「提交评价」：评价生效，计入对方平均分。
  - 取消：关闭本次评价（可后续在我的页补评）。
  - 重复评价：同一交易只记一次，不重复计。
- **入口·出口**：从「我买到的」完成交易操作弹出；出口到「我的」列表、对方主页。
- **依赖**：交易完成状态；评价存储与主页平均分计算。

# 用户流程

## 用户流程：逛与买（主路径）

- **触发**：有购买意向的学生打开首页，浏览或搜索二手商品。
- **主路径**：
  1. 首页按分类浏览或搜索「高数教材」（首页·商品广场）→
  2. 输入关键词/价格区间筛选，按最新排序（首页·商品广场）→
  3. 点开一件商品查看大图、价格、新旧、校区、卖家信用（商品详情页）→
  4. 点「私聊卖家」自动带入商品名开场白（站内私聊）→
  5. 约定线下见面当面交易（站内私聊）→
  6. 在「我买到的」点「完成交易」（我的页面）→
  7. 弹出互评界面打分提交（评价页）。
- **异常分支**：
  - 搜索无结果 → 首页展示空态提示「没有找到相关商品」。
  - 商品已下架 → 详情页显示「该商品已下架」并隐藏私聊按钮。
  - 卖家不回复 → 买家可返回首页继续浏览其他商品。
- **边界情况**：空态提示引导换关键词；下架商品不可发起新会话。

## 用户流程：发布商品

- **触发**：学生有闲置商品想出售，从首页「发布」进入。
- **主路径**：
  1. 进入发布页（发布商品页）→
  2. 单页一步填完标题、描述、价格、图片、新旧、校区（发布商品页）→
  3. 点「发布」提交，校验通过即发布成功（发布商品页）→
  4. 提示跳转「我的」列表，商品进入对应分类（我的页面）→
  5. 可随时编辑或下架（我的页面）。
- **异常分支**：
  - 校验失败（标题空/价格负数/图片超 9 张）→ 标红提示，不提交。
  - 发布后立即下架 → 商品从广场与搜索结果移除。
- **边界情况**：空标题、负价格、超量图片均被拦截。

## 用户流程：站内私聊

- **触发**：买家在商品详情页对某件商品感兴趣，想与卖家沟通。
- **主路径**：
  1. 详情页点「私聊卖家」（商品详情页）→
  2. 自动生成开场白「你好，请问 [商品名] 还在吗？」（站内私聊）→
  3. 双方互发文本消息（站内私聊）→
  4. 必要时发送图片补充细节（站内私聊）→
  5. 会话自动保存，可随时回查（站内私聊）。
- **异常分支**：与同一卖家重复发起 → 去重合为同一会话，不新建。
- **边界情况**：历史记录可回查；开场白保证至少一条消息。

## 用户流程：完成交易与互评

- **触发**：线下交易完成后，任意一方在「我买到的」点「完成交易」。
- **主路径**：
  1. 点「完成交易」（我的页面）→
  2. 系统弹出互评界面（评价页）→
  3. 对「信用态度」与「商品相符度」分别打五颗星（评价页）→
  4. 填写简短文字（选填）后提交（评价页）→
  5. 评价展示在对方主页并计入平均分（我的页面）。
- **异常分支**：
  - 取消完成交易 → 流程中止，不触发互评。
  - 重复评价 → 同一交易只记一次。
  - 未评先离开 → 可在「我的」页面后续补评。
- **边界情况**：重复提交被拦截；被评方主页实时更新平均分。

# 排除项（不在本期范围）

- 物流配送：不提供寄送，仅线下当面交易。
- 担保交易 / 线上支付：不代收代付，线下验货付款。
- 移动 App：仅网页版。
- 匿名评价：评价实名展示。
- 平台仲裁 / 申诉：平台不介入线下纠纷。
