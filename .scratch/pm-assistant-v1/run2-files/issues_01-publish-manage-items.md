# 01 — 商品发布与管理

**What to build:** 用户可以单页表单发布一件二手商品（标题、描述、≤9张图片、价格、新旧程度、交易校区），发布成功后商品进入广场对应分类并可被检索；用户可在「我的」列表查看自己发布的商品，随时编辑或下架，下架后商品从广场与搜索结果移除。样式与交互见 prd.md 第 3 章「发布商品页」「我的页面」；数据字段与状态机见 prd.md 第 4 章 4.1 商品。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 当我在发布页填写合法标题、价格≥0、图片≤9张并点「发布」→ 系统提示发布成功并跳转「我的」列表。
- [ ] 当标题为空 → 系统标红提示「标题必填」，不提交。
- [ ] 当价格输入负数 → 系统标红提示「价格需≥0」，不提交。
- [ ] 当上传第10张图片 → 系统拒绝并提示最多9张。
- [ ] 当发布成功后我在「我发布的」点「下架」→ 商品从广场与搜索结果立即移除。
- [ ] 当我点「编辑」→ 发布页预填该商品信息，修改后保存生效。
- [ ] 当商品已被下架我再点「重新上架」→ 商品恢复为在售并回到广场与搜索结果（推断值，见 prd.md 4.1 状态机）。
