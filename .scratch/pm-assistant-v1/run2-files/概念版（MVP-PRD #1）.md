# 概念版（MVP-PRD #1）

**核心用户**：在校大学生（买卖双方均为本校学生）。
**要解决的一件事**：提供一个比微信群刷屏更高效、可检索、可沉淀信用评价的二手闲置商品交易平台，支持线下当面交易。
**产品形态**：网页版（Web）。
**MVP 功能**：
1. 商品发布与检索 — 单页表单发布闲置（含图、价、新旧、校区），可按分类/关键词/价格检索浏览。
2. 站内私聊 — 商品详情页一键发起站内会话，免加微信协商细节与约定见面。
3. 交易互评 — 「完成交易」触发双方五维星级互评，沉淀信用供后续买家参考。
**本版本不做什么**：
- 物流配送、担保交易/线上支付、移动 App、图片相似搜索、跨校区筛选、语音/视频通话、消息已读回执、匿名评价、平台仲裁申诉。
**商业模式**：暂无直接盈利（校内信任场景以规模优先）；预留信息流广告位与付费置顶作为后续变现方向（推断值）。
**外部依赖声明**：无（登录走平台账号体系，不上第三方 SDK；无支付、无地图、无云存储依赖——图片上传走平台自身存储，不依赖外部 AI/推送服务）。
