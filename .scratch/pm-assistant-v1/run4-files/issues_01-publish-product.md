# 01 — 商品发布（卖家发布商品）

**What to build:** 用户在发布商品页填写标题、描述、分类、价格、成色、图片、联系方式并提交，商品立即上架并置顶出现在商品列表页顶部。必填项缺失或图片上传失败时给出明确提示，重复提交被拦截。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 当我填写全部必填项（标题/分类/价格/图片/联系方式）并点击「提交发布」→ 系统校验通过并上架 → 跳转到商品列表页，新商品置顶出现。
- [ ] 当我未填写任一必填项 → 系统不跳转 → 对应字段标红提示「带 * 为必填项」。
- [ ] 当我上传图片失败 → 上传区显示失败提示 → 我可重试上传。
- [ ] 当我重复点击「提交发布」→ 系统防止重复提交 → 仅保留一次上架记录，成功后跳转列表。
- [ ] 商品发布表单结构、字段与校验规则见 prd.md 第 3 章「发布商品页」；商品实体字段与状态机见 prd.md 第 4.2 节。
