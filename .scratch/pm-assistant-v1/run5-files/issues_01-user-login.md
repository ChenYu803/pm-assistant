# 01 — 用户登录与身份识别

**What to build:** 用户通过学校 CAS 统一认证登录平台；首次登录可设置昵称与头像（可跳过，跳过则用默认值）；未登录时浏览受限（私聊/发布）会被引导登录，登录成功后回到原意图操作；昵称与头像展示在商品详情「卖家信息」与消息会话列表中。数据模型见 prd.md 第 4.1 节，流程与边界见 prd.md 第 5 章「登录与身份识别」。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 当我未登录访问首页 → 可浏览商品列表与详情，但点「私聊卖家」或「+ 发布闲置」→ 系统先引导登录 → 登录成功后回到原意图操作
- [ ] 当我首次登录成功 → 系统引导设置昵称与头像 → 我可选择跳过 → 跳过则使用默认昵称与默认头像（推断值）
- [ ] 我设置的昵称与头像展示在商品详情「卖家信息」与消息会话列表中（推断值）
- [ ] 当 CAS 认证失败或超时 → 显示认证失败提示 → 留在登录引导页，不进入平台
