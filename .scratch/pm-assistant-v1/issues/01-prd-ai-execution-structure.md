# AI 执行版 PRD 结构设计（路线 A）

Status: ready-for-human
Type: grilling

## 背景

ADR-0002 已定：PRD 的读者是 AI（「只会执行的程序员」），v1.0 重构 PRD 结构，走路线 A——**业务规格完整，技术决策留给 AI**。现有落地版五维度（用户流程/状态机/字段规范/文案规范/异常处理）对人友好、对 AI 太粗犷。

## 课题

AI 执行版 PRD 的骨架长什么样：维度清单、文档组织方式、与精简版（人读叙事）及需求分析.md 的关系。v1.0 的核心课题，grilling 阶段仅登记不展开——需要一个空旷的上下文窗口专门讨论（to-spec 阶段进行）。

## 已知讨论素材（grilling 遗留，供参考）

- 现有五维度缺：页面清单、实体级数据模型（字段按功能散落而非按实体聚合）、功能清单与优先级/MVP 边界、验收标准
- 「文案规范」对 AI 零价值，倾向砍掉（或降级为一行「文案基调」）
- 精简版 PRD（三视角确认 + 概念版 ≤300 字 + 范围冻结）是否保留并承担「人读叙事」（求职展示/教学/小红书素材），待定
- 验收方式：作者本人拿真实 PRD 实际 vibe coding 一次跑通
