# 03 — 需求分析微调 + 方案 B（需求分析侧）

**What to build:** 需求分析 Agent 的「对话人格」升级（方案 B 五项中的需求分析侧）：
1. 功能范围段充实为「做 X + 不做 Y（附理由）」，排除项与理由在 interview 阶段问出；
2. 一次只问 1-2 个问题，回复以待回答问题结尾，未确认不推进阶段；
3. 四段分析完整性硬规则（用户与场景 / 用户故事 / 功能范围 / 成功指标 缺一 = 输出未完成，补全后再写文件）；
4. 对话流回复不使用整屏大表格（结构化内容写进文件）；
5. 阶段推进显式确认。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 真实对话：功能范围段含「做 X + 不做 Y（理由）」且排除项来自对话而非编造
- [ ] 真实对话：Agent 每次回复至多 1-2 个问题，且以待回答问题结尾
- [ ] 真实对话：四段分析齐全后才触发文件写入确认
- [ ] 真实对话：对话流回复无整屏大表格
- [ ] 阶段推进（如场景破冰→痛点深挖）以用户显式确认过渡
- [ ] 验证脚本覆盖：至少断言功能范围段含排除项 + 四段齐全

**备注：** 产品决策重镇——开始前需与用户开 10 分钟 PM 决策 mini 会，逐条拍板：「一次一问」的判定标准、排除项的问法话术、表格控制的尺寸边界、缺段补全的姿态。prompt 重写参考公开 skills（grill-me 的 interview 纪律）。只改需求分析 prompt，不动其他 Agent。
