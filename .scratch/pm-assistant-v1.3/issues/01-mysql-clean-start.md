# 01: MySQL 空库与初始化基础

**What to build:** 维护者可以用项目命令把一套空的 MySQL 9.7.2 LTS 环境准备成 PM Assistant 可连接的数据库；配置、应用连接身份和错误诊断不依赖 Workbench 手工操作。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 接入与当前 Next.js/Node.js 运行环境及 MySQL 9.7.2 LTS 兼容的数据访问方案，并保留当前 MongoDB 路径供后续分批迁移期间使用。
- [ ] 数据库地址、端口、库名、应用连接身份和密码来自环境变量或本机配置，真实凭据不进入代码或仓库。
- [ ] 初始化/升级命令可重复执行，负责建立迁移元数据和仅服务本项目的应用连接身份；重复执行不报假失败，也不破坏已建立结果。
- [ ] Workbench 可以继续使用 `root`，网站运行时不使用 `root`。
- [ ] MySQL 未启动、配置错误、权限不足或版本不满足时，维护者能获得可定位信息；用户层不暴露密码、连接串或原始堆栈。
- [ ] 若顺手提供开发重置命令，必须明确限制为开发环境；未提供不阻塞本票完成。
- [ ] 当前 v1.2 功能在此扩展阶段仍可运行，尚未迁移的行为不被提前破坏。
