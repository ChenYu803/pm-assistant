# 06: 项目与工作记录级联删除切换

**What to build:** 用户删除 MySQL 中的项目或工作记录时，所有属于删除范围的关联数据被完整清理；失败返回真实结果并可安全重试，不留下可重新访问的残留。

**Blocked by:** #03 — 对话、恢复与并发切换；#04 — 项目成果与 tickets 交付切换；#05 — 显式冻结流程切换

**Status:** ready-for-agent

- [ ] 项目删除覆盖工作记录、tab、消息、文件上下文、项目文件、快照、tab 操作、消息文件来源和冻结关联，确认全部清理后才报告成功。
- [ ] 工作记录删除清理其 tab、消息、文件上下文、tab 操作和相关来源记录，同时保留项目级文件和快照的既有边界。
- [ ] 删除期间的新写入不能在父级删除后留下孤儿；事务失败或重复请求具有可重入的清理结果。
- [ ] MySQL 外键、事务和必要的应用补偿共同保证对外语义，不依赖 MongoDB 嵌入式写许可或聚合清扫。
- [ ] 删除成功后旧 URL 一致返回不存在；删除失败不得显示成功。
- [ ] 项目级和工作记录级 replay 检查所有关联表的可观察结果，并覆盖中途失败和重复删除。
