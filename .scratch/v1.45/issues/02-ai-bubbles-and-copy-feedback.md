# 02: AI 回复气泡与原文复制反馈

**Type:** task

**Status:** ready-for-agent

**What to build:** 用户能清楚区分 AI 和自己的消息、舒适阅读长文，并复制该条 AI 回复的原始内容，得到约定的轻量反馈。

**Blocked by:** 无（可直接开始）。

**风险预估：** L1。**主责故事：** 41、51–54、64–65。**行为验收：** T16 的气泡、T17。

## 产品经理在 Agent 开始前提供

无新增前置输入。

## 需要用户协作的环节

Agent 提供短文、长文、流式及失败后保留文字的实际页面，用户确认阅读宽度和视觉区分。

## 验收条件

- [ ] AI 说明、自由回复和成果正文有清晰容器；与用户消息区分，长正文不铺满整个工作台。
- [ ] 复制逐字符采用保留的模型输出原文，包括 Markdown 与原有标记；不复制净化展示内容或渲染后的纯文本。
- [ ] 成功只有该条按钮图标暂变 √，随后恢复；按钮附近无成功文案，顶部无成功提示。
- [ ] 失败在页面顶部显示 Toast，两秒消失；不同消息的按钮状态不互相干扰。
- [ ] 停止或失败后已经展示的文字仍可阅读复制；浏览器证据覆盖原文一致性及成功、失败反馈。
