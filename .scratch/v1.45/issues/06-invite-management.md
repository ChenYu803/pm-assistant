# 06: 邀请码完整码长期管理与批量作废

**Type:** task

**Status:** ready-for-agent

**What to build:** 管理员无需填写原因即可管理邀请码，长期查看复制完整码，并从清晰列表批量作废未领取码。

**Blocked by:** 无（可直接开始）。

**风险预估：** L2。**主责故事：** 56–60、64–65。**行为验收：** T18。

## 产品经理在 Agent 开始前提供

无新增前置输入。

## 需要用户协作的环节

Agent 先提供真实可操作的管理页，用户确认列表、选择、批量操作和复制体验。

## 验收条件

- [ ] 创建、单个及批量作废均不要求原因，接口不强制原因；保留管理员身份校验和动作、操作者、时间记录。
- [ ] 新码持久保存完整值，管理员刷新或重登仍可查看复制；取消遮挡、仅本次显示和独立临时生成模块。
- [ ] 列表直接显示邀请码本身，领取账号与领取时间分列，保留必要状态和管理动作。
- [ ] 批量只作废未领取码，已领取记录和已到账积分保持；与领取并发时结果一致，不误伤权益。
- [ ] 普通账号不能通过页面或接口读取完整管理列表或执行管理操作；隔离验证覆盖持久查看、复制、权限及批量状态。
- [ ] 历史摘要不声称能还原完整码；旧码与 100 个新码的实际接续由 07 负责。

## 规格依据

[v1.45 spec](../spec.md) 第 4.8–4.9、5.2（T18）、5.4 节；用户故事与行为验收映射见本票顶部。

本票来自用户已确认的 [14 票拆分记录](../ticket-plan.md)；执行顺序见 [v1.45 任务入口](../map.md)。
