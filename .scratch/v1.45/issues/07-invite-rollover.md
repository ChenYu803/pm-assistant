# 07: 旧邀请码作废与 100 个新码接续

**Type:** task

**Status:** ready-for-agent

**What to build:** 用可重复核对的版本接续，将旧未领取码作废并生成恰好 100 个可长期查看的新码，保留已领取权益。

**Blocked by:** 06「邀请码完整码长期管理与批量作废」（[票据](06-invite-management.md)）。

**风险预估：** L2。**主责故事：** 60–61、65。**行为验收：** T19。

## 产品经理在 Agent 开始前提供

无新增产品输入。

## 需要用户协作的环节

无新增产品设计要求；生产执行随版本发布安排，不因本票的隔离演练自动操作生产。

## 验收条件

- [ ] 隔离演练证明旧未领取码不可再兑换，新码为 100 个且完整值持久可查、可正常按原规则兑换。
- [ ] 保留已领取记录、账号关联、领取时间与已到账积分，不修改账号、权限或其他积分来源。
- [ ] 接续重复执行、执行中失败和恢复不会重复生成一批或导致旧码与新码状态失配。
- [ ] 交付可执行的接续方式、执行前后核对项与隔离证据；实际生产执行时按部署纪律另留安全副本与核对记录。
- [ ] 本票完成条件为接续能力及隔离验证，不把尚未发生的生产执行记为完成。

## 规格依据

[v1.45 spec](../spec.md) 第 4.8–4.9、5.2（T19）、5.4 节；用户故事与行为验收映射见本票顶部。

本票来自用户已确认的 [14 票拆分记录](../ticket-plan.md)；执行顺序见 [v1.45 任务入口](../map.md)。
