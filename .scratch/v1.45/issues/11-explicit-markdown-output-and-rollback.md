# 11: 原型与 PRD 显式输出、会话成果与一版回退

**Type:** task

**Status:** ready-for-agent

**What to build:** 原型与 PRD 用户通过醒目输出按钮一次生成并保存自己的 Markdown 成果，同会话更新、跨会话新建，并可回退紧邻上一版。

**Blocked by:** 无（可直接开始）。

**风险预估：** L2。**主责故事：** 28–31、33–36、38、40–42、64–65。**行为验收：** 对应阶段的 T07、T09–T13，相关 T15。

## 产品经理在 Agent 开始前提供

无新增前置输入。

## 需要用户协作的环节

Agent 提供可运行的输出与完成按钮、生成状态及错误状态，用户确认可见性和文案；协议与存储由 Agent 决定。

## 验收条件

- [ ] 输出位于“完成本阶段”左侧，两者醒目；服务端明确区分聊天与输出，只有显式输出动作能授权本票阶段正式成果的生成保存。
- [ ] 本票阶段所有历史候选、确认接口及旧兼容入口不能绕过授权；普通聊天的写入措辞和自发文件标记不保存正式成果，历史文字可看可复制。
- [ ] 新会话首次输出新建成果，即使注入旧文件；首次按“阶段名-主题.md”命名、撞名加序号，后续以稳定成果身份更新自己的文件并保持名称。
- [ ] 完整正常生成且保存成功才原子更新正文和唯一上一版；停止、故障、截断、保存失败都不改已有正文及备份，已展示文字保留；可结算不等于可保存。
- [ ] A → B → C 只可 C → B，消耗备份后不能再回 A 或重做 C；用户手工改过的实际当前正文成为被替换备份，既有编辑改名删除权限保留。
- [ ] 输出不完成或跳阶段，完成不调用模型、不生成文件；原型对话 HTML 预览继续可用，不变成正式 Markdown 交付物的替代。
- [ ] 幂等、重试、并发、停止、断线、用量和项目归属沿用现有机制；保存来源可追溯，删除会话不删除已保存资产与备份。
- [ ] 以公开入口和隔离替身覆盖成功、失败、回退及权限；共享输出调用与普通 Markdown 成果机制供 12、13 复用。
