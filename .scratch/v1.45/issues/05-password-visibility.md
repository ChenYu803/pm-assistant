# 05: 全部密码框显示与隐藏

**Type:** task

**Status:** ready-for-agent

**What to build:** 用户可用每个密码框旁的眼睛按钮核对输入，并随时恢复隐藏。

**Blocked by:** 无（可直接开始）。

**风险预估：** L1。**主责故事：** 62、65。**行为验收：** T20。

## 产品经理在 Agent 开始前提供

无新增产品输入。

## 需要用户协作的环节

无新增产品协作要求；Agent 依据已定行为完成。

## 验收条件

- [ ] 覆盖登录、注册、找回密码、个人中心修改密码及其中所有确认密码字段。
- [ ] 每个按钮只影响对应输入，切换不清空、不改变值，也不触发表单提交。
- [ ] 眼睛按钮有可辨识操作名称，可通过键盘使用，默认遵循密码隐藏方式。
- [ ] 编译及最轻量的相关浏览器检查覆盖全部实际字段，不为此运行真实邮箱或模型流程。

## 规格依据

[v1.45 spec](../spec.md) 第 4.8、5.2（T20）、5.4 节；用户故事与行为验收映射见本票顶部。

本票来自用户已确认的 [14 票拆分记录](../ticket-plan.md)；执行顺序见 [v1.45 任务入口](../map.md)。
