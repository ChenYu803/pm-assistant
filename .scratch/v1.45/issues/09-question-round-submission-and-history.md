# 09: 题卡作答、一次提交与历史回看

**Type:** task

**Status:** ready-for-agent

**What to build:** 用户可逐题作答、修改草稿、提交部分或全部答案，并按轮回看；任何未提交历史轮仍能提交，已提交轮保持原快照。

**Blocked by:** 08「共写三阶段提示词并打通首轮题卡」（[票据](08-requirements-prompt-and-first-round.md)）。

**风险预估：** L2。**主责故事：** 9–11、15–18、20–21、42、65。**行为验收：** T01 的作答、T02、T04、相关 T03／T05／T06／T12。

## 产品经理在 Agent 开始前提供

无新增产品输入。

## 需要用户协作的环节

无新增产品决策要求；Agent 实现可运行交互，题卡最终视觉在 14 与用户共同收敛。

## 验收条件

- [ ] 上一题、下一题保留选择和自由填写；草稿、当前位置及问答关系在刷新与切回同会话后恢复，不额外请求模型。
- [ ] 可提交部分或全部答案；未答保持未答，每轮只提交一次，重复点击和网络重试不重复调用或扣分。
- [ ] 提交时带完整问题、选项、答案、未答与来源身份，模型继续规划下一轮；不把孤立字母或“是”当作全部上下文。
- [ ] 所有轮保留，可按轮回看；浏览位置不改变上下文，不混入其他会话问答。
- [ ] 未提交历史轮始终能修改并提交，已提交轮包括部分提交均不能补答后重交，原快照持续可查。
- [ ] 编辑、重生成、失败和重试不抹掉已提交轮或历史关联；无效新题卡保留已有题目和答案。
- [ ] 隔离证据覆盖部分提交、重放、刷新、会话隔离与历史状态；补充形成的新旧轮顺序组合在 10 验证。
