# 01: 工作台合栏、滚轮与输入区可见性

**Type:** task

**Status:** ready-for-agent

**What to build:** 合并项目信息和四环导航，用户进入桌面工作台后即可操作完整输入框与发送按钮，并用滚轮阅读长对话。

**Blocked by:** 无（可直接开始）。

**风险预估：** L1。**主责故事：** 43–45、64–65。**行为验收：** T16 的布局与滚动。

## 产品经理在 Agent 开始前提供

无新增前置输入；现有 spec 足够开始。

## 需要用户协作的环节

Agent 先提供实际可操作页面，用户反馈并确认合栏后的层级、密度和操作感；不在开工前要求用户画布局。

## 验收条件

- [ ] 项目、积分、返回入口与四环导航合并组织，减少顶部占高，保留必要信息和自由导航入口。
- [ ] 在 1440 × 900、1366 × 768 下完整输入框和发送按钮稳定可见；长回复、侧边栏开关时可操作。
- [ ] 对话区可独立滚动，鼠标滚轮有效；窄屏不丢失关键入口，基础键盘操作和焦点可用。
- [ ] 与现有消息和后续题卡采用一致的高度、溢出约束，不靠每增加一块内容就推长整个页面。
- [ ] 完成适用编译、浏览器检查与用户实际页面反馈记录；后续题卡组合状态在 14 复核。

## 规格依据

[v1.45 spec](../spec.md) 第 4.7、4.9、5.2（T16）、5.3–5.4 节；用户故事与行为验收映射见本票顶部。

本票来自用户已确认的 [14 票拆分记录](../ticket-plan.md)；执行顺序见 [v1.45 任务入口](../map.md)。

## 实施与验证要求

- 开工前复核风险分级，按仓库规定完成适用编译和本票相关检查。L1 先报备所需脚本；L2 完整运行相关验证并按改动触点回归相邻范围，不用全量重复验证代替有目的的检查。
- 验证题卡、权限、文件、计量或数据接续时，优先复用公开 HTTP／浏览器、隔离 MySQL 与本地模型替身；首个需要 v1.45 回放的功能票负责必要的运行器版本登记，后续复用，不另建测试框架。
- 真实模型样例先说明假设、预计时长和调用范围；预计超过 10 分钟先按仓库规则取得用户同意。不因本票自动发送真实邮件、执行生产迁移、部署或 push。
- 验收条件当前均待实现验证。完成时在本票记录实际行为证据、检查结果、必要的用户反馈与协作确认及已知限制，再推进任务入口和 PROGRESS；不转交给一张覆盖全版的最终人工验收票。
