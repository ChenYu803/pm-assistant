# 08: 原型 HTML 快照

**What to build:** 在原型设计阶段，根据当前会话和按手动上下文规则加载的文件生成可查看、下载和再次打开的 HTML 原型快照。快照属于项目资产，但不进入项目文件树，也不能被普通上下文文件引用；生成失败时用户能明确看到失败并重试。

**Blocked by:** 03: 阶段会话隔离；06: 手动上下文与 Agent 读取边界

## 产品经理在 Agent 开始前提供

- 实施模式：正式代码直接实现。
- 无新增输入。在原型阶段的正式工作区内实现 HTML 生成、预览、下载、再次打开、失败和重试；沿用 02 工作台和项目现有视觉语言。

**Status:** resolved

- [x] 用户可以查看、下载并再次打开同一 HTML 快照。
- [x] HTML 快照不出现在项目文件树或上下文文件列表中。
- [x] 生成失败不会显示为成功；已有快照和未确认候选保持不变并可重试。
- [x] 快照操作不会自动完成阶段或写入结构化 Markdown。
- [x] 快照列表、详情和反馈与正式工作台一致，产品经理可以直接在真实生成流程中验收。
