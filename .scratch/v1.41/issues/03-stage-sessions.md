# 03: 阶段会话隔离

**What to build:** 用户可以在同一阶段创建多个地位相同的阶段会话，切换会话并分别保留消息和过程状态。每个会话都能独立进入工作区并保留自己的上下文引用；会话之间不串用消息、过程状态或上下文文件。

**Blocked by:** 02: 四环导航与工作区入口

## 产品经理在 Agent 开始前提供

- 实施模式：正式代码直接实现。
- 无新增输入。以 02 已落地的工作台、会话列表和聊天区为基线，在正式产品中补齐创建、切换和空会话状态；会话删除由 16 号票实现。

**Status:** resolved

- [x] 同一阶段可以创建至少两个会话，任一会话都能进入工作区。
- [x] 切换会话后消息和过程状态互不串用；刷新后仍恢复正确会话。
- [x] 每个会话保留自己的上下文文件引用，不会自动继承其他会话的引用。
- [x] 创建和切换会话不会改变其他阶段状态，也不会自动写入项目文件。
- [x] 新增界面沿用 02 正式工作台的视觉语言，产品经理可以直接在正式页面验收并提出修改。
