## 用户可用行为与事务边界

- 注册输入邮箱、密码和 6 位数字邮箱验证码；不填写邀请码即可创建账号，保留注册后自动登录和安全回跳。旧的 REGISTRATION_MODE / REGISTRATION_INVITE_CODE 不再控制正常注册。
- 登录继续使用邮箱密码，登录页提供“忘记密码？”入口；找回成功后用户使用新密码登录。
- 邮箱统一 trim / lowercase；验证码绑定规范化邮箱与 register / reset-password 用途，10 分钟有效，60 秒后可重发。只允许最新一次成功投递的验证码使用；重发开始即废弃旧码，发送失败不能退回旧码。
- 单个验证码最多允许 5 次错误；跨码、用途的邮箱校验额度和 IP 额度由 MySQL 原子计数，重启或多进程不会清零。验证码只持久化 HMAC-SHA256 摘要，密钥复用 AUTH_SECRET；响应、正式日志不输出验证码或凭据。
- 在同一 MySQL 事务里创建账号/更新密码和消费验证码；重复或并发消费不能重复生效。数据库邮箱唯一约束继续兜底。密码使用 bcrypt cost=12，新注册/重置保持至少 6 字符并限制最多 72 UTF-8 字节，避免 bcrypt 截断歧义；登录保留旧版超过 72 字节密码的兼容，升级夹具使用 96 字节随机旧密码回归。
- 注册事务只建立账号，不发放积分；当前仓库尚无 #04 的积分账本，新账号没有注册赠送。#05 可在注册返回成功后独立兑换，兑换失败不能回滚已提交的账号。
- 新增迁移 0024：users.email_verified_at 默认 NULL；新增验证码与认证限流表。未重写历史迁移，不清理旧账号、项目或正文；旧账号可直接登录，不虚构已验证时间。

## 服务端限流

| 边界 | 限制 |
| --- | --- |
| 注册/找回/发码入口的异常请求 | 同 IP 150 次 / 15 分钟，正文最多 4096 字节 |
| 发码 | 同邮箱 6 次 / 小时、同 IP 30 次 / 小时；另有邮箱+用途 60 秒间隔 |
| 验证 | 同邮箱 20 次 / 15 分钟、同 IP 60 次 / 15 分钟；单码最多 5 次错误 |
| 正常登录 | 同账号 ID 20 次 / 15 分钟（不存在账号按规范化邮箱）、同 IP 60 次 / 15 分钟 |

额度是安全节流，没有注册人数的产品配额。登录按查得的稳定账号 ID 统一邮箱重音变体额度；桶自增与本次计数读取在同一连接的事务里持锁完成，避免并发请求误读更晚计数。生产只从受信任 nginx 覆写的 X-Forwarded-For 取地址；本机开发统一使用 local，忽略来访者伪造的代理地址。nginx 必须沿用 deploy/ubuntu/ideastage-proxy.conf 中覆盖该头的配置，Next 端口不对公网开放。时间控制只改变隔离邮件的发送/到期时间，不跳过真实限流。
