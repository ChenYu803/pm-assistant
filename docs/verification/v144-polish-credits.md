# v1.44 #08 文件润色积分验收

日期：2026-11-03。任务：[08 文件润色接入同一积分计量与结算](../../.scratch/v1.44/issues/08-polish-credit-settlement.md)。风险 L2：共享调用链、账号余额、持久金额及并发。

## 实现与边界

- 沿用 #07 账号锁、完整输入预算、赠送优先分摊与可靠成本 × 2000 结算。三个真实模型入口（旧会话、新阶段、文件润色）均通过 ai.ts；共享计量入口强制要求调用身份与预算，移除润色例外。
- 新增 0030_v144_polish_generation_results，仅保存可恢复预览，无业务级联外键。结果正文、completed 与结算同事务。GET 恢复查询不重发上游；账号+requestId 和完整输入摘要防重放、冲突及跨入口复用。
- 当前四环工作台和旧文件编辑器均展示本次预留、实际消耗、待核对/免单。不应用或关闭不撤销已发生正常费用；应用只改草稿，显式保存仍走既有修订逻辑。保存成功清正文草稿，失败保留；费用与不采用状态仍可恢复。
- 缺可靠 usage 时完整预览仍可用，资金为 pending；截断、空结果及供应商故障免单但保留供应商成本。提交后的暂时回读失败不把已完成终态改为网站故障。

## 验证环境

所有应用验收均使用随机 v141_replay_* MySQL 库、正式 HTTP/浏览器流程及本机供应商替身，真实模型费用 0。runner 核对从零初始化、重复迁移、旧账号增量升级及清理。没有操作日常/生产库，没有执行目标机迁移、部署或真实模型请求。隔离运行的应用模式 live 仅连接 127.0.0.1 替身；场景标为 replay 防止误访问真实供应商。
