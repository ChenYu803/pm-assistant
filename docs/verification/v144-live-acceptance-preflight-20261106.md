## 模型预算预检

目前可定位的本机官方样本合计为 **8 次请求、0.000127 CNY 已确认成本、5 笔待确认成本**。其中待确认成本不能按 0 处理；已有记录还明确说明这些样本不能推出从开发到首批试用的完整历史累计支出。因此当前不能计算可信的 200 CNY 剩余额度，也不能在缺少账单或完整历史台账时继续新增付费请求。

本票后续若获准执行，需在第一笔新增请求前补齐：

1. 开发至首批试用的历史模型支出来源和累计金额；
2. 5 笔待确认样本的处理状态，或明确将其作为未决上界纳入预算；
3. 供应商当前可核验余额或账单快照；
4. 本轮每类样本的请求数、最大输出限制、预估费用上限和停止样本的未知成本处理；
5. 200 CNY 累计预算的有依据剩余额度。

在上述账目闭合前，不能宣称精确余额、不能以“单次很便宜”为依据开跑，也不能把供应商余额当作累计预算的替代品。
