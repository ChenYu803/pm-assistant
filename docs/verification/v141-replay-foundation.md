# v1.41 基础业务回放（19 号票）

运行入口：

```powershell
npm run verify:v141-replay-foundation
```

使用与 `db:init` 相同的本机 MySQL 配置和维护账号，要求 `AI_MODE=replay`、依赖已安装且 Playwright 可以启动 Edge。脚本不连接既有开发服务，也不清空 `.env.local` 中的业务数据库。

每次执行独立创建随机命名的空测试数据库和专用应用账号，按正式迁移初始化两次，并在注册前检查全部业务表为空。随后将当前正式源码与构建配置复制到同盘 `.next` 下的临时目录，通过依赖链接启动随机本机端口的 Next 开发服务，完成桌面及 390px 移动端连续回放。沿用项目的 Turbopack 编译器，不复制 `.env.local`，也不停止日常开发服务；浏览器发送消息前再次核对服务端确实处于 replay。

回放使用正式界面完成注册、退出后登录、创建项目与两个产品迭代、目标选择与风险确认、改名、四环跳转、阶段完成与重新打开，以及多个会话切换。公开 API 和数据库最终结果用于交叉核对编号、阶段、消息、上下文和项目文件事实。

先验证空阶段导航和会话切换不会自动创建文件，再显式准备一份项目文件夹具，验证非空上下文在两个会话间隔离、文件树在两个产品迭代间共享。夹具只服务于基础隔离断言，不代表已通过成果候选确认、文件修订或任务整套交付验收。

日志、初始空库计数、截图与结果 JSON 存在运行输出的临时证据目录，账号密码不会写入结果。成功或失败收尾均尝试停止本次服务、删除本次确实创建的测试库和应用账号；清理失败也会导致非零退出码。本票不运行真实模型，也不替代 20—24 号票的专项和最终发布验收。
