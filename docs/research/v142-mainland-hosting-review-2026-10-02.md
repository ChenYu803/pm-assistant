# v1.42：中国大陆用户的上线方案复评

研究日期：2026-10-02。用途：个人面试作品、少量免费试用；用户确认 v1.41 已全部完成。本轮只评估发布路线，不购买、部署、迁移数据库或进行网络实测。外部事实仅采用官方来源；方案取舍另标为判断。

## 结论

**判断：Vercel + Supabase + 阿里云域名技术上可行，但“大陆面试官能顺畅打开并完成操作”不能由这套组合或免费额度保证。** 应分别回答容量、网络和改造成本三个问题。少量演示可能远未用满免费额度，却仍因跨境网络、空闲暂停或单次生成时限而演示失败。

**建议：** 若主要目标变为大陆用户可靠访问，优先比较“中国内地云服务器 + 现有 Next.js + MySQL + 域名 + ICP 备案”。若不想等待备案，可比较香港服务器，但只有实际目标网络测试通过后才把它作为演示入口；香港地理位置本身不是线路保障。原方案可以作为极低现金支出的试验路线，不宜直接承诺大陆可用性。

本轮建议不自动撤销已确定的 PostgreSQL 方向。若用户选服务器并保留 MySQL，再单独修改 v1.42 决策与验收范围。

## 为什么购买 .cn 域名不能解决承载网络

Vercel 明确说明其没有中国大陆服务器或 CDN 节点，可能出现高延迟、限速或不可访问。使用自定义域名是官方列出的缓解措施，但即使完成优化，Vercel 也不保证中国大陆的可用性和性能。官方还不建议在 Vercel 部署前额外放置代理。[Vercel：中国大陆访问说明](https://vercel.com/kb/guide/accessing-vercel-hosted-sites-from-mainland-china)

**推论：** 阿里云注册域名只决定域名购买与管理服务；DNS 指向 Vercel 后，网页和 API 的实际承载仍在 Vercel。`.cn` 后缀或阿里云 DNS 不会自动提供大陆应用服务器、改变数据库所在地或消除跨境链路。自定义域名值得使用，但不能视为线路修复方案。

## 备选架构及其代价

| 路线 | 对本项目的主要价值（判断） | 主要成本或前提 |
| --- | --- | --- |
| Vercel + Supabase + 阿里云域名 | 托管部署方便，有免费额度，日常基础设施维护较少 | 仍要迁移 PostgreSQL；适配函数时限、连接与跨请求状态；跨境访问和免费项目暂停需要处理 |
| 中国内地轻量应用服务器 + Next.js + MySQL + 域名 | 保留已完成的 MySQL 功能，用户到网站及应用到数据库可避免跨境访问 | 对外提供网站服务前需 ICP 备案；服务器有固定成本；自己负责更新、HTTPS、进程恢复和数据库备份 |
| 中国香港轻量应用服务器 + Next.js + MySQL + 域名 | 保留 MySQL；按云厂商说明无需因该非内地承载申请 ICP 备案 | 从大陆访问仍走跨境路径，可能高延迟、丢包或不可达；仍有服务器费用和运维工作 |

阿里云规定：使用中国内地轻量应用服务器对外提供网站服务前须申请备案；非中国内地地域不需要该 ICP 备案。申请其备案服务号所用轻量服务器购买时长需至少三个月。以上仅说明此部署场景的 ICP 条件，不等于网站其他运营要求自动满足。[阿里云：轻量应用服务器使用须知](https://help.aliyun.com/zh/simple-application-server/product-overview/usage-notes)

阿里云官方列有中国香港轻量地域，但明确提醒香港及海外与中国内地网络非直连，可能出现较大延迟、丢包和无法访问；套餐带宽峰值也不是强保障承诺。其建议优先选择靠近目标用户的地域。[阿里云：地域与网络连通性](https://help.aliyun.com/zh/simple-application-server/product-overview/regions-and-network-connectivity)

腾讯云同样提供香港轻量服务器，并明确跨境运营商线路可能导致延迟和丢包；其中国内地轻量服务器绑定域名开办网站须备案。[腾讯云：地域与网络连通性](https://cloud.tencent.com/document/product/1207/50103/)

腾讯云另有需要购买的“优选流量包”，可为香港、新加坡轻量服务器到大陆方向提供线路加速。这是额外付费产品，不能把普通香港实例当作已经具备该线路，也不据此承诺任何具体用户网络可用。本轮不引入其费用，也不将其作为首发必需项。[腾讯云：优选流量包快速入门](https://cloud.tencent.com/document/product/1207/104336)

## 保留 MySQL 的实际含义

**工程判断：** 把 Next.js 和 MySQL 放在同一台小型服务器上，适合低流量作品的初始架构，可以省去 PostgreSQL 迁移与跨云数据库链路。其代价是应用和数据库共用一个故障点，必须有独立于该机器的数据备份，并接受自己维护系统与进程。这里提出的是架构选择，不是已验证的容量或零改造承诺。

当前仓库的 MySQL 版本限制、初始化脚本和部署配置仍需正式核对；云服务器不能直接宣称“上传代码就可上线”。如使用远程数据库，还须核对连接池、TLS、访问范围和凭据配置。若继续使用 Vercel，则保留 MySQL 与采用 Supabase 也是两个可分别评估的选择，Vercel 本身不强制使用 PostgreSQL；只是跨平台数据库连接和公网链路不会因此消失。

## 免费套餐与当前代码适配

截至研究日期，Vercel Hobby 每月包含 100 GB Fast Data Transfer、4 CPU 小时、360 GB 小时配置内存用量及 100 万次函数调用；它限个人非商业用途，免费公开访问不自动意味着任何商业用途都符合条款。按目前个人作品展示用途判断可以作为候选，未来运营收费需重新核对。[Vercel Hobby](https://vercel.com/docs/plans/hobby)

启用 Fluid Compute 的 Hobby 单次函数默认及最大时限为 300 秒，处理请求和发送流式响应均计入；函数请求/响应还受 4.5 MB 大小限制。不能通过仅开启流式输出来规避总时限。[Vercel Functions 限制](https://vercel.com/docs/functions/limitations)

Supabase Free 包含每项目 500 MB 数据库、1 GB 文件存储、5 GB egress 和另列的 5 GB cached egress，最多两个活跃项目；共享计算资源，闲置一周暂停，不含套餐自动备份。存储桶额度和数据库额度不同，存进数据库的 Markdown、聊天、HTML 不能按 1 GB Storage 计算。[Supabase 价格页](https://supabase.com/pricing) 暂停项目可以从 Dashboard 恢复，但官方该页没有承诺恢复耗时；应在面试前检查，无法依靠此操作保证面试官任意时刻访问。[Supabase 上线检查](https://supabase.com/docs/guides/deployment/going-into-prod)

容量判断：若只由本人和少数面试官使用，文本为主、低并发，免费容量大概率够用；这不是性能或成本压测结果。模型 API 额度另行计算，开放生成入口需要有用量边界。

代码复核：`src/lib/mysql.ts` 直接使用 mysql2；`src/lib/mysql-iteration-workbench.ts:382` 当前上游超时仍为 600 秒，循环累计完整回复后返回，消息 API POST 等待完成才发 JSON；`src/lib/generation-control.ts` 的取消控制器为进程内 Map。平台时限、实例隔离和中断后状态收口都需要适配。`src/lib/mysql-config.ts` 的管理员初始化路径仍校验已验证 MySQL 9.7.2，现有本机验收不能代表云端其他版本已经兼容。

若保留原平台方向，建议 Next.js 服务端访问 Supabase PostgreSQL、保留现有 NextAuth 认证，以减少浏览器直连额外跨境域名；这是工程建议而非已实施结果。Supabase 当前数据库区域列表包括新加坡、东京等，未列中国大陆；应按开户时实际可选区域让应用函数和数据库尽量同区，并使用适合 serverless 的连接池，不能假定 Vercel 已默认部署亚洲。[Supabase 区域](https://supabase.com/docs/guides/platform/regions)、[数据库连接方式](https://supabase.com/docs/guides/database/connecting-to-postgres)

## 用于决策的验证门槛

以下是建议，并非本轮已执行的测试：

1. 使用真实部署域名，在中国大陆普通网络、关闭代理的条件下，检查首页、登录、项目加载、生成、成果确认与下载；至少覆盖两种实际运营商网络。
2. 关注完整链路而非只看首页：用户 → 网站/API → 数据库，以及 API → 模型服务。数据库区域应尽量靠近应用服务器；模型服务也须由部署环境实际连通。
3. 不只做一次快速访问；在准备展示的时段确认冷启动、空闲恢复、长回复及刷新后的成果仍可用。
4. 面试演示准备可立即打开的样例成果与本机回放，降低临场等待的不确定性；这不能替代对外链接的可用性验收。

## 价格与研究限制

本轮不引用未核验的促销价，也不将首年新用户价格当续费价格。服务器价格取决于地域、账户活动资格、配置、流量、购买时长与续费；域名和模型调用另计。未在大陆各运营商进行本项目部署实测，所以不能给出“香港一定更快”或“Vercel 一定打不开”的结论。最终应以目标用户的真实访问结果和购买页结算条件判断。
