# v1.42 采用 Vercel、Supabase 与阿里云域名上线

Status: superseded by ADR-0007（2026-10-10；以下保留原决策的历史记录）

2026-09-27，产品经理决定暂停 v1.41 后续迭代，以快速、低成本上线为 v1.42 的目标：Vercel 承载应用，Supabase PostgreSQL 作为本轮上线数据库，域名通过阿里云购买。MySQL 相关代码保留供未来使用；本决策调整 ADR-0005 对后续上线版本的数据库方向，不改写 v1.3 的历史事实。

首发以个人面试展示和免费试用为用途，主要保留入职体验，并补齐实践路线的最小四环成果闭环。用户选择 Vercel 与 Supabase 的免费套餐方向；Supabase 从全新数据库开始，不迁移现有账号、项目、对话或文件，本机 MySQL 数据原样保留。现有 MySQL 实现及初始化脚本保留，v1.42 只对 PostgreSQL 发布验收，未来切回 MySQL 作为独立任务。

这需要实际迁移 MySQL 数据访问、建表和事务语义，不能仅替换连接地址。本轮不承诺双库同步、自动回退或即时切库；认证选择、最小成果闭环细节、试用访问边界、模型费用及发布验收条件仍待收敛。讨论记录见 `.scratch/pm-assistant-v1.42/discussion.md`。
