# v1.3 以 MySQL 作为唯一应用数据库

Status: accepted

v1.3 将 PM Assistant 的应用数据库从 MongoDB 切换为 MySQL，MySQL 以空数据库开始，不迁移旧 MongoDB 数据，也不提供切换后的 MongoDB 回退路径；MongoDB 可以留存在本机，但不再是应用运行依赖。选择这一方案是因为当前旧数据对用户没有保留价值，而未来部署目标更适合围绕 MySQL 建立单一数据事实源；同时，应用连接 MySQL 使用仅服务本项目的专用连接身份，Workbench 继续使用 `root`。

## Consequences

- v1.3 必须按全新安装验收，用户需要重新注册并创建项目。
- 迁移实现仍需完整保持 v1.2 已有用户行为，包括消息恢复、并发、冻结、文件来源和级联删除。
- 验收失败时修复 MySQL 实现，不把双数据库同步或数据回搬作为 v1.3 范围。
- 初始化/升级命令需要负责建立数据库结构和应用连接身份，避免依赖 Workbench 手工操作。
- 数据库类型不出现在用户界面；v1.3 不要求实际线上部署，但配置不能锁死未来部署。
- 数据库瞬时不可用时，当前操作明确失败并允许用户重试，不引入后台排队或无限自动重试。
