# v1.42 改为中国大陆服务器承载

Status: accepted（国内承载方向；购买和部署尚未执行）

2026-10-10，用户调查并比较长期费用、跨境访问及运行风险后，最终选择中国大陆服务器，接受先办理 ICP 备案的时间成本。此决策替代 ADR-0006 的 Vercel/Supabase 发布方向及随后海外 VPS 的试做路线；不再推进 PostgreSQL 迁移，继续以已经验收的 MySQL 实现和同机数据库方案为部署基础。云端新建数据库，本机数据库及数据原样保留。

用户当前选中的候选为腾讯云上海轻量应用服务器：4 核、4 GB、40 GB SSD、300 GB 流量包、3 Mbps 峰值带宽、1 年，截图价格 109 元。该配置是少量面试展示、同机 MySQL 与另两个轻量站点的合理起点，尚未测容量；套餐资格、最终价格和续费价以实际订单为准。Ubuntu 24.04 LTS 系统镜像为建议，截图的 Ubuntu + Docker 基础镜像也可用；镜像和搭配购买产品尚未被用户最终确认，不作为已接受架构。

国内部署先按源站 HTTPS 访问，不把 Cloudflare 作为必需环节。软件版本、运行资源、登录、持久数据、DeepSeek 调用与长生成仍需部署验收；此前本机 replay 通过不能替代这些证据。网站公开前完成 ICP 备案，可并行准备代码、系统和部署配置；本轮仅记录决策和解释购买项，未付款、开通资源或部署。
