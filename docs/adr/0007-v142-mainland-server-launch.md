# v1.42 改为中国大陆服务器承载

Status: accepted（国内承载及配置已敲定，用户已确认付款；部署尚未验收）

2026-10-10，用户调查并比较长期费用、跨境访问及运行风险后，最终选择中国大陆服务器，接受先办理 ICP 备案的时间成本。此决策替代 ADR-0006 的 Vercel/Supabase 发布方向及随后海外 VPS 的试做路线；不再推进 PostgreSQL 迁移，继续以已经验收的 MySQL 实现和同机数据库方案为部署基础。云端新建数据库，本机数据库及数据原样保留。

用户最终敲定腾讯云广州轻量应用服务器配置：Ubuntu 24.04 LTS 系统镜像、4 核 CPU、4 GB 内存、3 Mbps 带宽、40 GB SSD 系统盘、300 GB 流量额度。2026-10-10 用户已确认付款；尚未核对实例运行状态或开展远程部署。此前截图为一年 109 元；购买时长、套餐资格、最终价格、流量账期和续费价以实际订单为准。

首发准备按纯 Ubuntu 直接部署网站、MySQL 与网站入口，暂不引入宝塔或 Docker；软件版本、服务管理、HTTPS 和备份在部署准备阶段确定。该配置是少量面试展示、同机 MySQL 与另两个轻量站点的合理起点，尚未测运行容量和构建峰值。

六项搭配购买均非当前首发必需：COS 标准存储、付费 SSL 证书、点播体验包、身份证 OCR、CLS 资源包和轻量对象存储。建议先不购买，尚未被用户确认；HTTPS 可用免费证书并配置续期，应用日志需保留和轮转，数据库需离机备份，但这些要求不强制购买对应附加产品。轻量对象存储基于 COS，与标准 COS 的文件存储用途重叠，不自动扩容系统盘；截图一个月套餐和一年套餐不能只比标价。CLS 的 U 是计费抵扣单位而非 GB，超额或到期继续使用可产生按量费用。

国内部署先按源站 HTTPS 访问，不把 Cloudflare 作为必需环节。软件版本、运行资源、登录、持久数据、DeepSeek 调用与长生成仍需部署验收；此前本机 replay 通过不能替代这些证据。网站公开前完成 ICP 备案，可并行准备代码、系统和部署配置。服务器付款由用户完成，Agent 尚未开通资源或部署。
