# ADR-0001 — 目标用户群从在职 PM 转为求职 PM

MVP 验证了「多 Agent 流水线 + md 交接物」的产品形态，但原定位「在职 PM 的效率工具」与实际情况不符：产品作者本人是求职中的大二学生，没有在职 PM 用户渠道，也无法验证在职 PM 场景的真实性——坚持该定位会让产品成为自嗨。

**决策：目标用户群改为求职 PM**（无 PM 工作经验的求职者），增长走三步走：① Dogfooding——自己作为唯一用户，把产品打磨成「自己想要的样子」（兼作简历叙事）；② 以教学之名经营小红书等社群账号，引流其他求职 PM 使用；③ 未来随用户群成长再回在职 PM 市场。

**被否备选**：坚持在职 PM 定位（缺用户渠道、缺验证条件）；直接面向企业/团队销售（无资源，且与求职目标冲突）。

**后果**：核心体验从「效率」变为「从 0 到 1 走通」——新人必须无引导走完「想法 → 需求分析.md → prd.md」，需要模板案例、新手引导、成果导出支撑；Agent 是否承担教学角色（而不只是流程执行）在 v1.0 规划中定夺。
