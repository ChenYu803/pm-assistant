# 指定 `test1@example.com` 为项目测试账号

Status: accepted

2026-11-04，用户指定 `test1@example.com` 作为本人在本项目中的测试账号，允许在本机开发、`replay` 和随机隔离验收环境中用于功能测试。该账号是测试数据，不代表真实可收信邮箱；需要证明真实注册或找回邮件送达时，必须使用可控且可收信的真实邮箱，不能以此账号或邮件替身代替。

本决策只指定测试用途，不授予管理员权限、不加入生产 `ADMIN_EMAILS`、不绕过邮箱验证、账号状态检查或其他现有鉴权，也不授权向日常/生产数据库写入测试数据、操作真实用户资金或产生未经单独批准的真实模型费用。测试账号在各环境中的存在、密码、邮箱验证状态和数据库迁移状态仍须分别核实；本决策本身不创建、启用、迁移或修改账号。

2026-11-04 用户提供的 `/profile` 错误截图显示 MySQL 报 `Unknown column 'account_status'`。这表明当前连接的数据库 schema 缺少代码所需字段，不是邮箱是否真实或账号是否被指定为测试账号所导致。修复需按部署纪律核实目标数据库、备份与迁移状态后执行，不由本决策授权自动迁移。
